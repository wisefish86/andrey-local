# andrey-local

Личная библиотека скриптов и справочных материалов. **Репозиторий публичный:** не хранить секреты, токены и конфиденциальные данные.

## Папки

- [Входящие](Входящие/README.md) — входящие материалы.
- [Заметки](Заметки/Горячие%20клавиши.md) — памятки Markdown.
- [Ресурсы](Ресурсы/README.md) — иконки и общие файлы.
- [Скрипты](Скрипты/README.md) — рабочие инструменты и системные BAT.
- [Справочные материалы](Справочные%20материалы/README.md) — справочные файлы.
- [.github](.github/workflows/build-shortcut-icons.yml) — автоматизация GitHub.

Служебные файлы `.gitignore`, `AGENTS.md`, `README.md` остаются в корне.

## Синхронизация

Все BAT, PS1 и скрытый VBS для синхронизации находятся в [Скрипты/Система GitHub](Скрипты/Система%20GitHub/README.md). В корне репозитория запускатели больше не дублируются.

- `Установить автосинхронизацию.bat` — установить или **переустановить задание Windows с новыми путями**.
- `Запустить синхронизацию GitHub.bat` — разовая синхронизация.
- `Запустить автосинхронизацию сейчас.bat` — запуск автоматической синхронизации вручную.

**После переноса обязательно переустановить задание** через BAT в папке `Скрипты/Система GitHub`: ранее зарегистрированное задание могло ссылаться на удалённый корневой `Автосинхронизация.ps1`. До переустановки автоматическая синхронизация может не работать.

Задание `AndreyLocal Inbox Auto Sync` проверяет репозиторий примерно каждые две минуты, пока пользователь вошёл в Windows. Оно может публиковать изменения в публичный GitHub. Журнал — `.auto-sync.log`.

## Ярлыки

Локальные ярлыки для BAT генерирует [система ярлыков](Скрипты/Система%20ярлыков/README.md) рядом с запускателями, без перезаписи пользовательских ярлыков. При переносе файлов старые ярлыки с абсолютными путями требуется обновить.
