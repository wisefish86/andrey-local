# andrey-local

Личная библиотека скриптов и справочных материалов. **Репозиторий публичный:** не помещай сюда токены, пароли и конфиденциальные настройки.

## Навигация

- [Заметки](Заметки/Горячие%20клавиши.md) — памятки Markdown, которые удобно открывать через ярлык.
- [Скрипты](Скрипты/README.md) — рабочие инструменты: Личные, Пение, Работа и системные.
- [Ресурсы](Ресурсы/README.md) — иконки и общие файлы.
- [inbox](inbox/README.md) — технические входящие файлы; название сохраняется для совместимости.
- [reference](reference/README.md) — проверенные материалы; название сохраняется для совместимости.
- [.github](.github/workflows/build-shortcut-icons.yml) — техническая автоматизация GitHub.

`AGENTS.md`, `.gitignore` и корневые файлы запуска — служебные. Не перемещать вручную.

## Синхронизация GitHub ↔ компьютер

**Главный запускатель:** `Синхронизация.bat` в корне. Он оставлен здесь, чтобы можно было быстро запустить синхронизацию.

Рабочая логика находится в [Скрипты/Система GitHub](Скрипты/Система%20GitHub/README.md). В корне сохранены небольшие совместимые PS1-запускатели: это защищает существующий BAT, старые ярлыки и задание планировщика Windows при переезде.

**Первоначальная установка автосинхронизации:** запусти `Установить автосинхронизацию.ps1` из корня через PowerShell. Задание `AndreyLocal Inbox Auto Sync` проверяет изменения примерно каждые две минуты во время входа в Windows. Обработка файлов `inbox` выполняется только по отдельной просьбе, а не автоматически.

Для отключения задания:

```powershell
Unregister-ScheduledTask -TaskName "AndreyLocal Inbox Auto Sync" -Confirm:$false
```

Фоновая автосинхронизация может публиковать изменения всего репозитория. Не помещай секреты даже во временные файлы внутри него. При конфликтах требуется ручная проверка. Локальный журнал — `.auto-sync.log`.

## Ярлыки и памятки

После синхронизации генератор создаёт отсутствующие ярлыки рядом с BAT в `Скрипты`; пользовательские ярлыки не перезаписывает. Для памятки [«Горячие клавиши»](Заметки/Горячие%20клавиши.md) создай обычный ярлык на рабочем столе и назначь Markdown-просмотрщик приложением по умолчанию.

**Входящие:** при команде «разбери inbox» можно распределить файлы; переносить в `inbox/done/` только после полного подтверждения обработки. Подробности в [inbox/README.md](inbox/README.md).
