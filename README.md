# andrey-local

## Автоматическая синхронизация GitHub ↔ компьютер

Уже есть ручной скрипт `Синхронизация.bat`. Для фоновой работы добавлены **`Автосинхронизация.ps1`** и **`Установить автосинхронизацию.ps1`**.

**Один раз после получения файлов из GitHub** откройте PowerShell в каталоге репозитория и выполните:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\Установить автосинхронизацию.ps1"
```

Windows Task Scheduler будет запускать проверку **каждые 2 минуты**, пока пользователь вошёл в Windows. Окна не открываются; ошибки записываются в `.auto-sync.log` (файл исключён из Git). Компьютер должен быть включён, Git должен иметь доступ к GitHub через существующую авторизацию GitHub Desktop/Git. Без первоначальной настройки на компьютере автоматика не запустится.

- Поступившие в GitHub коммиты подтягиваются в локальный `andrey-local` через `fetch` и `pull --ff-only`.
- Только новые/изменённые файлы **в `inbox/`** автоматически коммитятся и отправляются в GitHub (до 10 МиБ каждый; ограниченный список типов).
- Удаление файлов, конфликты, изменения вне `inbox/`, неизвестные расширения и очевидно опасные имена приводят к **остановке**, а не к потере данных.
- Когда одновременно есть локальные входящие файлы и новый коммит GitHub, используется `pull --rebase`; при конфликте нужна ручная проверка.
- Скрипт не синхронизирует FTP и не выполняет автоматическую сортировку файлов ChatGPT. Файлы в `inbox/done/` считаются обработанными, не обязательно задеплоенными.
- **Репозиторий публичный.** Автопубликация не умеет надёжно распознавать конфиденциальные сведения внутри разрешённых файлов. Не кладите сюда секреты, пароли, токены, персональные документы и приватные данные.

Отключить автоматическую проверку:

```powershell
Unregister-ScheduledTask -TaskName "AndreyLocal Inbox Auto Sync" -Confirm:$false
```

Ручная `Синхронизация.bat` остаётся для изменений вне `inbox/` и разрешения конфликтов.
