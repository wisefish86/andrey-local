# Закрытие программ

**Запуск:** `[скрипт] Закрыть рабочие программы.bat`.

Запускает соседний PowerShell для закрытия набора рабочих программ. Перед применением проверь список процессов в PS1; возможна потеря несохранённых данных.

**Ярлык:** после запуска общего генератора появляется рядом с BAT (`- ярлык.lnk`). Его можно скопировать в свою подборку. Существующий изменённый вручную ярлык не перезаписывается.
