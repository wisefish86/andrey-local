# Подмена ввода в Flow Launcher

AutoHotkey **v2**: когда активно окно Flow Launcher, ввод `b` заменяется на `и ` с переключением русской раскладки. Запуск через `Запустить замену раскладки.bat` (или непосредственно AHK). Требуется установленный AutoHotkey 2 с ассоциацией `.ahk`.

BAT использует расположенный рядом AHK; после синхронизации для BAT создаётся ярлык. Не запускать несколько экземпляров без необходимости.
