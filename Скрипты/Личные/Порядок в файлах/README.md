# Порядок в файлах — инвентаризация

**Запуск:** перетащите папку из Проводника Windows на `Сканировать-папку.bat`.

Программа создаёт подпапку `Результаты/scan_ГГГГММДД_ЧЧММСС` возле скрипта:
- `files.csv` — полный список относительных путей, размеров, расширений и дат.
- `folders.csv` — список папок.
- `summary.md` — общий обзор.
- `errors.txt` — только если были ошибки доступа.

Передайте три основных файла в ChatGPT, чтобы получить предложение по организации проектов. Скрипт **ничего не изменяет** внутри выбранной папки; содержимое файлов не читает. Исключаются служебные папки и точки повторного перехода.

Это только первый этап. Скрипт переноса файлов будет отдельным и должен иметь режим предварительного просмотра, журнал операций и возможность отката.

**Приватность:** отчёт включает названия и пути файлов. Проверяйте их перед отправкой. Каталог `Результаты/` не коммитьте в GitHub.
