# Порядок в файлах — сканер

**Как запускать:** перетащите нужную папку на `Сканировать-папку.bat`. Поддерживается Windows PowerShell 5.1.

Создаётся **один файл JSON** в папке `Results`. Его название включает **имя сканируемой папки и время запуска**, например `Мои проекты_20261015_123456.json`.

В JSON содержатся название и исходный путь сканируемого каталога, все относительные пути файлов и папок, размеры файлов, даты создания и изменения, статистика и возможные ошибки доступа. Этот отчёт можно передать в ChatGPT для анализа и составления плана переносов.

Сканер работает **только на чтение**: он не изменяет пользовательские файлы, не извлекает содержимое документов, не считает контрольные суммы. Служебные каталоги и точки повторного перехода исключаются.

**Кодировка:** JSON записывается в UTF-8 с BOM для Windows; исходный PowerShell-код написан ASCII-символами во избежание проблем Windows PowerShell 5.1. Если кириллица некорректно отображается в программе для просмотра, открывайте JSON как UTF-8.

**Конфиденциальность:** `Results/` исключён через `.gitignore`; не загружайте инвентаризации в GitHub, если там есть личные названия или пути. При необходимости отчёт удобнее прикрепить прямо к чату. Отчёты, уже добавленные в GitHub ранее, не исчезают автоматически из истории.

Скрипт для **изменения** структуры файлов будет отдельным: предварительный просмотр, журнал и откат обязательны.
