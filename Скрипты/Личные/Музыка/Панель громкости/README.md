# Панель громкости для выступлений

Открывает компактную панель громкости поверх окон; кнопки `+`/`−` меняют системную громкость, контекстное меню закрывает программу. Нужен **AutoHotkey v2**.

Запускай `Открыть панель громкости.bat` или AHK непосредственно. Ярлык для BAT создаётся генератором автоматически.
