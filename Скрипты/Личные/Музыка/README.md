# Музыка, пение и выступления

Каждая подпапка — самостоятельный рабочий комплект:

- `Перед выступлением/` — подготовка перед пением и очистка имён файлов.
- `Подготовка фонотеки/` — подготовка музыкальных файлов.
- `Распределение минусов/` — операции с каталогами для Syncthing.
- `Обновление тегов/` — массовая обработка метаданных Mutagen. `check_only.bat` предназначен для проверки, `apply_all.bat` вносит изменения.
- `Исправление лирики/` — графический Python-инструмент для встроенных текстов песен.
- `Репертуар для сайта/` — данные и конвертер репертуара плюс HTML-представление.

Старые резервные ZIP и копии кода исключены из рабочей структуры. Перед массовым переименованием или изменением тегов желательно проверить результат на небольшой тестовой партии.
