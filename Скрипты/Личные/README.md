# Личные инструменты

Каждая подпапка — отдельная задача или инструмент со своим исходным кодом, запускателем и краткой инструкцией.

- `Импорт из Anytype в Notion/` — импорт данных; читать README и код перед запуском.
- `Порядок в файлах/` — сканирование структуры папок в JSON, без изменения файлов.

Новые файлы для разбора сначала складывай в `inbox/scripts/`. Когда инструмент обновлён в GitHub, автосинхронизация получает изменения на компьютере.
