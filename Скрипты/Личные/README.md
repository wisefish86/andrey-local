# Личные

Инструменты для повседневных задач. Сейчас:
- `Автоматизация/` — ввод текста в Flow Launcher, закрытие программ.
- `Импорт из Anytype в Notion/` — конвертация/импорт, отдельная инструкция.
- `Порядок в файлах/` — сканирование файлов, без изменения содержимого.
- `Резервное копирование настроек/` — настройки программ на Яндекс Диск, расписание из JSON.

Оставляем существующие папки до проверки их зависимостей. Новые простые инструменты можно класть непосредственно в `Личные/Название задачи/`, не создавая уровни категорий без необходимости. Ярлыки автоматически создаются рядом с запускаемыми файлами.
