# Горячая клавиша экспорта Anytype (черновик)

Файл: `Anytype-Export.ahk` (AutoHotkey **v2**). Запускается отдельно от существующего `Import.ps1`.

## Первый запуск
1. Установить AutoHotkey v2, открыть `Anytype-Export.ahk`.
2. Открыть объект Anytype. Навести мышь на **три точки** и нажать **Ctrl+Shift+1**.
3. Открыть меню вручную, навести мышь на **Export** и нажать **Ctrl+Shift+2**.
4. Открыть диалог экспорта, выбрать **Anytype Block v2 (Preview)**, навести мышь на окончательную кнопку **Export** и нажать **Ctrl+Shift+3**.
5. Закрыть диалог без экспорта и попробовать **Ctrl+E** на объекте Anytype.

Координаты сохраняются в `Anytype-Export.local.ini` рядом со скриптом. Это **локальная настройка**, её не публиковать в GitHub. Важно: координаты относительны клиентской области окна; при изменении масштаба, расположения кнопок или версии Anytype перенастроить.

## Что реализовано
- Ctrl+E действует только при активном `Anytype.exe`.
- Три откалиброванных клика запускают штатный UI-экспорт.
- Ожидание появления **нового** окна Проводника (до 15 секунд), закрытие только этого окна и возврат фокуса в Anytype.
- Защита от повторного запуска и диагностические сообщения.

## Что пока НЕ реализовано
- Проверка наличия и корректности ZIP; появление Проводника **не доказывает успешность** экспорта.
- Изменение свойства «В Notion» через API: сначала нужно надёжно определить ID именно открытого объекта и ID свойства. **Не отмечать автоматически, пока экспорт не подтверждён.**
- Автозагрузка: после успешного теста можно поместить ярлык скрипта в `Win+R → shell:startup`.
- Обработка UI с разными размерами и локалями; сейчас используются откалиброванные координаты.

## Секреты
Ключ Anytype уже сохранён локально в Windows Credential Manager как Generic Credential с target `Anytype-Local-API`. **Ни API-ключ, ни его резервную копию не добавлять в этот репозиторий.** В текущей версии скрипт вообще не читает ключ.

## Безопасность
Сначала тестировать на неважном объекте. Скрипт ничего не удаляет и не меняет свойства Anytype. Папка содержит также существующий независимый импортёр `Import.ps1` — его не изменяли.
