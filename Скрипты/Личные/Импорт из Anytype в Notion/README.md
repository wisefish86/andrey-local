# Импорт из Anytype в Notion

**Запуск:** `Запуск импорта.bat` — пользовательский запускатель для `Import.ps1`.

Перед использованием проверь входные файлы и требования в коде `Import.ps1`: способ импорта и последствия нельзя определять только по названию. Не запускай повторный импорт без проверки риска дублей в Notion.

Правки исходного скрипта и BAT сохраняются вместе в этой папке; ярлык Windows создаётся для BAT автоматически.
