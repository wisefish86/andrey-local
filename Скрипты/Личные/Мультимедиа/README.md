# Мультимедиа

`Нормализация аудио видео.bat`: перетащи один видеофайл. Скрипт использует **ffmpeg** из PATH, копирует видеопоток без перекодирования и обрабатывает звук. Создаёт соседний файл с суффиксом `_norm`. Результат и параметры нормализации нужно проверять на тестовом видео; на ПК запуск пока не тестировался.
