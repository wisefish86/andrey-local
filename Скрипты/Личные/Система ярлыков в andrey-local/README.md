# Ярлыки рядом со скриптами

Генератор `Обновить-ярлыки.ps1` ищет запускаемые BAT, AHK и PYW в `Скрипты/`, а также корневые BAT в `andrey-local`. Для каждого создаёт `Название - ярлык.lnk` **рядом с исходным файлом**. Если у PYW есть BAT-запускатель в той же папке, отдельный ярлык PYW не нужен.

- Для запуска: `Обновить ярлыки.bat`. Генератор также вызывается после Git-синхронизации.
- Иконки берутся из `Ресурсы/Иконки/ICO/` по `icon-map.json`.
- **Существующие актуальные ярлыки не перезаписываются**, поэтому можно вручную менять иконку, имя и другие свойства. Чтобы пересоздать конкретный ярлык, удали только его `- ярлык.lnk` и запусти генератор.
- Генератор теперь автоматически удаляет только **устаревшие ярлыки, созданные этой системой**: если их BAT/AHK/PYW больше не существует или больше не входит в список запускаемых файлов. Пользовательские ярлыки не трогаются.
- Локальные новые LNK не отправляются в Git благодаря `.gitignore`. Уже вручную добавленные пользовательские LNK не удаляются и не изменяются.
- Папка `Ярлыки/` остаётся личным каталогом Андрея. Генератор её не наполняет и не очищает.
- Папка `Ярлыки/` по-прежнему не чистится автоматически: она считается отдельным личным каталогом.
- `-WhatIf` у PS1 покажет будущие пути без создания файлов.
- Если копируешь ярлык в другое место, он продолжает указывать на исходный BAT/AHK. При переносе папки репозитория такие ярлыки потребуется пересоздать.

**Внимание:** система не запускает BAT/AHK при генерации. Проверять реальные скрипты после переименования или переноса по-прежнему необходимо.

## Проверка и восстановление повреждённых ярлыков

Запусти `Проверить и восстановить ярлыки.bat`: **по умолчанию это только диагностика**, никакие ярлыки не меняются.

Для восстановления после просмотра списка можно запустить этот BAT с аргументом `-Apply` (например, из PowerShell: `& '.\Проверить и восстановить ярлыки.bat' -Apply`). Меняются только ярлыки с точной служебной подписью `Managed by AndreyLocal Shortcut Catalog v1`, для которых найден единственный соответствующий запускаемый файл в той же папке. При сомнении выводится `REVIEW`, ничего не меняется. Обычные и вручную добавленные ярлыки, папка `Ярлыки` и уже корректные ссылки остаются нетронутыми.

Перед каждым исправлением исходный `.lnk` копируется в `Backups/ShortcutRepair-YYYYMMDD-HHMMSS/`, там же сохраняется `repair-log.csv`. Для отмены скопируй нужный исходный файл из папки резервной копии обратно по его относительному пути. Генератор `Обновить ярлыки.bat` и обычная Git-синхронизация **не запускают ремонт**.

Важно: подпись есть только у ярлыков, созданных генератором; старые ярлыки без подписи требуют ручной проверки. Значки и пользовательские ярлыки автоматически не переназначаются. Повреждения, вызванные перенесением самого репозитория, могут потребовать проверки списка `REVIEW`.
