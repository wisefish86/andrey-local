# CorelDRAW ↔ JSON: быстрая корректура текста

**Импортируемые модули VBA:** `CorelJSONExport.bas` и `CorelJSONImport.bas` (оба в **CP1251 / ANSI** для русской Windows). Редактируемые UTF-8-исходники — одноимённые `.utf8.txt`, не импортировать их как BAS.

## Установка

1. Синхронизируйте репозиторий и откройте VBA-редактор CorelDRAW 2026.
2. Удалите старый модуль `CorelJSONExport`, если он уже установлен. Импортируйте оба `.bas`.
3. Откройте и сохраните исходный CDR, запустите `Main_ExportCorelJSON`.
4. Возьмите JSON в подпапке `data` рядом с CDR и передайте его GPT. JSON содержит содержимое макета — **не публиковать в GitHub**.
5. Сохраните полученный от GPT патч как UTF-8 `<папка CDR>\data\CorelJSONPatch.json`.
6. Сохраните CDR (`Ctrl+S`) и запустите `Main_ImportCorelJSON`. Просмотрите план и подтвердите применение; после проверьте макет и сохраните CDR.

**Для импорта открывайте именно тот исходный документ, по которому выполнен экспорт.** Если после экспорта текст вручную изменился, импортёр пропустит объект.

## Патч JSON

```json
{
  "schema": "coreldraw-text-patch/v1",
  "sourceFile": "Имя исходного документа.cdr",
  "changes": [
    {
      "id": 12345,
      "old": "Положить руку поверх другой руки",
      "new": "Положите одну руку поверх другой"
    }
  ]
}
```

`sourceFile` должен **точно** совпадать с `sourceFile` экспортного JSON. `id` берётся из экспортного поля `textObjects[].id`, `old` копируется без изменений (с точными пробелами и переносами), `new` — исправленный текст **всего объекта**. Для патча достаточно только изменённых объектов, не включайте исходный список целиком. Кодировка патча — UTF-8; стандартное экранирование JSON поддерживается.

## Что делает экспортёр

- Обходит страницы, ищет `cdrTextShape` рекурсивно, получает `StaticID`, страницу, имя, слой и **полный текст**. В отличие от прежнего v2, не запрашивает тяжёлые параметры шрифтов, цветов и посимвольного оформления.
- Сохраняет `data\CorelJSONExport_YYYY-MM-DD_HH-MM-SS.json`. Не редактирует CDR.
- Сохраняет `schema: coreldraw-text-fast/v2` для совместимости, добавляет `complete`, `summary`, `warnings`. При ошибках чтения или достижении предела экспорт помечается `complete: false`.
- До 2500 объектов или 30 секунд **между вызовами CorelDRAW**; длительный отдельный COM-вызов не прерывается. Полнота поиска внутри PowerClip не подтверждена.

## Что делает импортёр

- Читает **только** `data\CorelJSONPatch.json` и проверяет схему, имя документа, наличие изменений, ID, дубликаты и точное совпадение исходного текста.
- Показывает число допустимых изменений; перед применением делает копию сохранённого CDR в `data\backup_YYYYMMDD_HHMMSS.cdr`. Если CDR не сохранён после последних правок, импорт блокируется.
- Для каждого допустимого изменения вычисляет общий префикс/суффикс и заменяет **только изменённый непрерывный текстовый диапазон** через CorelDRAW `Text.Range(...).Replace`, чтобы сохранить форматирование остального объекта. Переносы строк **в изменяемом диапазоне**, чистые вставки и удаления автоматически не применяются.
- Группирует операции в одну команду отмены. Не сохраняет исправленный CDR автоматически. Записывает `data\CorelJSONImport_report.txt` со сводкой и причиной пропусков.
- Не изменяет другие текстовые объекты, геометрию, шрифты и изображения.

## Ограничения и безопасность

**Это первая тестовая версия, а не проверенный production-макрос.** Статически проверяется исходник; компиляция и работа в CorelDRAW 2026 ещё не проведены. Используйте **копию CDR** до первой успешной проверки.

- Замена изменённого диапазона не гарантирует сохранение *внутреннего* смешанного форматирования непосредственно внутри этого диапазона. Остальной текст не переписывается. Для сложной смешанной верстки проверять результат визуально.
- Переполнение абзацных текстовых рамок **пока не определяется автоматически** — после импорта обязательно проверяйте.
- Копия сохраняется на диске перед изменениями, но если отдельная операция вызывает ошибку после частичного изменения, возможна необходимость `Ctrl+Z` или восстановления из резервной копии.
- Если исходный документ был закрыт и пересоздан с другими `StaticID`, изменения не применятся; это безопаснее, чем заменить неверный текст.
- Исправление текста по смыслу, особенно медицинских и правовых инструкций, проверяйте отдельно.
