# CorelDRAW → JSON: быстрый экспорт текста (v2)

**Файл импорта:** `CorelJSONExport.bas` (Windows-1251 / CP1251 для русского VBA CorelDRAW 2026).  
**Редактируемая копия:** `CorelJSONExport.utf8.txt` (UTF-8; НЕ импортировать как BAS).  
**Процедура запуска:** `Main_ExportCorelJSON`.

## Быстрый запуск

1. Сохранить CDR на диск (для первого запуска желательно работать с копией).
2. Если старый `CorelJSONExport` уже импортирован, удалить модуль в редакторе VBA. Через **File → Import File** импортировать обновлённый `CorelJSONExport.bas`.
3. Запустить `Main_ExportCorelJSON`. Ничего выбирать и вводить не нужно.
4. Отправить JSON из папки `data` рядом с исходным CDR в ChatGPT. Не публиковать JSON в GitHub: он содержит тексты макета.

Пример пути: `Папка_макета\data\CorelJSONExport_2026-10-22_10-15-30.json`. Папка создаётся автоматически. Если файл с тем же временем уже есть, добавляется порядковый суффикс.

## Что экспортируется

- Текстовые объекты всех страниц и найденные вложенные в группы, без координат и геометрии графики.
- Идентификатор `StaticID`, индекс страницы, имя, слой, тип фигурного/абзацного текста и полный текст.
- Форматирование **на уровне объекта**: шрифт, кегль, жирность, курсив, подчёркивание, индекс, цвет (RGB/CMYK там, где доступен), ссылка на стиль.
- `complete`, `summary`, `warnings`, чтобы отличать полную выгрузку от прерванной.
- Дата экспорта и название исходного файла: предусмотрены для последующего импортёра.

**Экспорт не меняет CDR.** Параметры отдельно форматированных слов/символов, полные определения стилей и цвета нетекстовых плашек в быстром режиме **не экспортируются**. Если в одном объекте смешанные шрифты, свойства всей истории могут быть неоднозначны (`null` / смешанный статус). Для точечных текстовых замен JSON достаточен, для бережной правки смешанного форматирования потребуется отдельный выборочный экспорт.

## Производительность и ограничения

- Используется поиск текстовых объектов вместо полного обхода геометрии и тяжёлого чтения каждого символа.
- Лимиты: до 2500 текстовых объектов и до 30 секунд, проверяемые **между** объектами. Если один вызов CorelDRAW заблокируется, лимит не сможет прервать его принудительно.
- `DoEvents` вызывается после каждых 10 объектов. VBA выполняется в CorelDRAW и не является независимым фоновым процессом.
- При достижении лимита JSON сохраняется с `complete: false`: не применять автоматический импорт патчей на основе неполной выгрузки.
- Если CDR не сохранён или каталог недоступен для записи, будет ошибка вместо сохранения в случайное место.
- Фактический запуск именно v2 в CorelDRAW 2026 и полнота поиска внутри PowerClip пока **не подтверждены**.

## Импортёр — следующий этап

При разработке импортёра по умолчанию искать JSON в `data` рядом с открытым CDR; сверять `sourceFile`, `schema`, `complete` и идентификаторы объектов. Не применять неполные или несоответствующие файлы автоматически. Использовать точечные изменения с предпросмотром и резервной копией.
