# CorelDRAW → JSON — экспорт структуры макета

**Модуль:** `CorelJSONExport.bas`  
**Запуск:** `Main_ExportCorelJSON`  
**Статус:** первая версия для проверки на реальном CDR; в CorelDRAW ещё не запускалась.

## Быстрый запуск

1. Откройте CDR в CorelDRAW и для первого прогона используйте копию.
2. Откройте редактор VBA (`Alt+F11`) → в проекте макросов выберите **File → Import File** и укажите `CorelJSONExport.bas`. Если кириллица в редакторе отображается как `????`, откройте модуль в Notepad++, преобразуйте в ANSI для русской локали Windows и импортируйте повторно.
3. Запустите процедуру `Main_ExportCorelJSON` через CorelDRAW. Укажите путь для `.json`.
4. Передайте полученный JSON в ChatGPT вместе с PNG или PDF предпросмотра страниц. **Не публикуйте JSON в GitHub**, он содержит тексты документа.

## Экспортируемые данные

- Страницы и их габариты (мм), обычные и мастер-слои, видимость и печать.
- Объекты и группы: `StaticID`, имя, тип, порядок, слой, размеры и расположение (мм), поворот и коэффициенты преобразования.
- Вложенные объекты групп и PowerClip, видимые атрибуты заливок и контуров, типы эффектов и прозрачности.
- Текст: исходное содержимое, фигурный/абзацный тип, переполнение, цепочка рамок, абзацы и форматирование каждого непрерывного фрагмента текста (`runs`), включая кегль, начертания, индекс, подчёркивание, зачёркивание и цвет.
- Нативные стили и наборы стилей: имена, категория, родитель и строковое представление свойств (когда доступно через API); привязка стиля к объектам и текстовым фрагментам.
- `missingProperties` — подсчёт недоступных свойств API по типу объекта, `warnings` — серьёзные проблемы чтения.

## Ограничения и проверки

- Это **только экспортёр**: не меняет CDR и не импортирует правки.
- Для градиентов, эффектов, художественных кистей и сложных объектов экспорт пока не является полным графическим представлением; предоставляется общая информация и типы.
- Цвет RGB может быть вычисленным представлением исходного цвета другой модели. Для производственного CMYK ориентируйтесь также на исходный документ/цветовую модель.
- `StaticID` стабилен для существующего объекта, но нельзя считать его универсальным идентификатором между независимыми копиями/пересозданными объектами.
- Содержимое `runs` следует сверить с `content`: пробелы, управляющие символы и импорт из SVG могут отличаться.
- **Обязательные испытания:** русский текст, разные шрифты в одном абзаце, стили с наследованием и локальными переопределениями, надстрочные/подстрочные, фигуры в группах/PowerClip, абзацный текст, скрытые и мастер-слои, фигуры с градиентом, поворот и растяжение.
- До первого успешного теста не считать JSON пригодным для обратного импорта изменений.
