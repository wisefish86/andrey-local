# Инспектор шрифтов для CorelDRAW 2026

**Модуль:** `FontInspector`. **Запуск:** `Main_FontInspector`. **Форма:** `frmFontInspector`.

## Назначение

Немодальная форма показывает названия шрифтов, обнаруженных в редактируемых текстовых объектах, и позволяет выделить конкретный объект в CorelDRAW. Режимы: весь документ / только выбранный стенд (включая группы и PowerClip). Текст в кривых нельзя проверить по названию шрифта.

## Установка

1. Расположить `FontInspector.bas`, `frmFontInspector.frm` и `frmFontInspector.frx` в одной папке.
2. В CorelDRAW 2026 открыть **Alt+F11**, выбрать VBA-проект. **File → Import File**: импортировать `.bas` и отдельно `.frm`. `.frx` импортируется вместе с формой.
3. Если CorelDRAW снова импортирует `.frm` как модуль: **Insert → UserForm**, назвать `frmFontInspector` через F4, открыть код формы F7 и вставить **ТОЛЬКО строки от `Option Explicit` и ниже** из исходного `.frm`. Удалить ошибочно импортированный модуль. Служебные строки `VERSION`, `Begin`, `Attribute` в редактор кода вставлять нельзя.
4. **Debug → Compile VBAProject**. Запустить `Main_FontInspector` через Alt+F8. При назначении горячей клавиши использовать процедуру с тем же именем.

## Работа

- Выделить стенд в CorelDRAW, запустить инспектор — автоматически выбирается «Только выделенное», если выделение есть.
- Форма появляется до анализа. Она периодически обрабатывает Windows-сообщения во время последовательного чтения символов; виден счётчик объектов и активна **«Остановить»**.
- Кнопка **«Взять выделение»** запоминает новые объекты. **«Проверить»** повторяет поиск.
- После завершения выберите шрифт и фрагмент; двойной клик или **«Перейти к объекту»** выделяет нужный текст, не закрывая форму.
- Отчёт при прерывании помечен как неполный. Большие тексты проверяются посимвольно для обнаружения разных шрифтов внутри одного блока.
- Объекты не меняются и не удаляются. Сохранение и переименование документа выполняйте вручную.

## Исправления

- Убрана неверная конструкция `.Font.Name`: используется `sh.Text.Story.Characters(offset, 1).Font` (строковое свойство API CorelDRAW).
- Из `UserForm_Initialize` убран блокирующий полный поиск. Форма сначала отображается; анализ идёт ограниченными порциями по 250 символов с `DoEvents`, прогрессом и остановкой.
- По умолчанию при наличии выделения проверяется только выбранный стенд. В случае большого числа объектов стадия составления очереди тоже может занять время.
- Кнопки сканирования блокируются во время поиска, чтобы не было повторного запуска; команда остановки остаётся доступной.

## Ограничения / проверка

**Не проверено в настоящем CorelDRAW 2026:** импорт, компиляция VBA, взаимодействие с заблокированными объектами, поведение на многотысячных макетах. `DoEvents` обеспечивает отзывчивость, но не создаёт отдельный поток и не гарантирует высокую скорость: точная посимвольная проверка всё ещё затратна. Требуется реальный тест.

Для окончательного подтверждения фирменных шрифтов проверяйте все редактируемые текстовые блоки; текст в кривых остаётся вне аудита. Сводка CDR может включать неиспользуемые имена шрифтов из стилей/метаданных.

Источник по API: https://community.coreldraw.com/sdk/api/draw/22/p/textrange.font

## Исправление открытия формы (05.11.2026)

В предыдущем варианте сканирование запускалось автоматически из `UserForm_Activate`, что могло блокировать отображение окна. Исправлено: окно появляется без анализа; для сканирования пользователь нажимает «Проверить». Переключение режима также не запускает сканирование автоматически. Если форма не загрузилась, `Main_FontInspector` теперь показывает текст ошибки.

После обновления `FontInspector.bas` и `frmFontInspector.frm` обязательно выполнить `Debug → Compile VBAProject` и проверить, что `frmFontInspector` находится в разделе Forms. Если импортируется как Module, создать пустую UserForm с этим именем и перенести только код от `Option Explicit`. Импорт и фактическая работа на компьютере с CorelDRAW 2026 пока не подтверждены.

## Важное: проблема с формой

Файл `frmFontInspector.frx` в предыдущем комплекте не был экспортирован из реальной формы `frmFontInspector` и поэтому **не является подтверждённо рабочим**. Не импортируйте текущую пару `.frm`/`.frx` как готовую. Для проверки самого запуска импортируйте отдельный стандартный модуль `FontInspector_Diagnostic.bas` и запустите `Main_FontInspector_Diagnostic`: он должен сразу показать обычный MsgBox и не зависит от формы. Это только диагностика, а не полноценный инспектор.
