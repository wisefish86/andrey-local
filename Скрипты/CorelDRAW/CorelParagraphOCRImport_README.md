# Импорт OCR в CorelDRAW 2026 — одна страница, 300 dpi и PF Din

**Модуль:** [CorelParagraphOCRImport.bas](./CorelParagraphOCRImport.bas), кодировка **Windows-1251** для импорта в русскую VBA-среду. [UTF-8 исходник](./CorelParagraphOCRImport.utf8.txt) для GitHub. Запуск `Main_ImportPosterOCR`.

## Назначение

Создать **один новый документ с одной страницей**, содержащий абзацные текстовые рамки по пиксельным координатам **всего изображения**. Два плаката рядом на одном PNG остаются одной композицией. Исходный CDR не изменяется.

- Физические размеры `canvas_width_mm`, `canvas_height_mm` в JSON имеют приоритет перед DPI.
- Если точных размеров нет, используются `dpi_x`, `dpi_y` из JSON, иначе **300 dpi по умолчанию**.
- Для картинки **2048 × 1331 px** это **173,4 × 112,7 мм** при 300 dpi. Если картинку предварительно сжимали, DPI не восстанавливает исходный физический размер — нужно передать точные миллиметры.
- Координаты `x_px, y_px, width_px, height_px` считаются от верхнего левого угла **всего** изображения, а не каждого плаката.
- Для заголовков — **PF Din Text Cond Pro Medium**; для основного текста — **PF Din Text Cond Pro Light**; для выделений — **PF Din Text Cond Pro Bold**. Шрифты должны быть установлены на компьютере с CorelDRAW; для объектов с ролью `emphasis` / `bold` / `highlight` используется Bold. При необходимости имена можно заменить в JSON (`font_title`, `font_body`, `font_bold`).
- Каждый `blocks[]` создаётся в виде **редактируемой Paragraph Text рамки**. Ширина рамки не меняется, при переполнении уменьшается кегль. Ручная проверка обязательна.
- OCR должен сохранять оригинальный текст без смысловых исправлений, сомнительные фрагменты отмечаются `needs_review`.

## Как пользоваться

1. В CorelDRAW откройте редактор VBA через `Alt+F11`.
2. Если установлен прежний модуль `CorelParagraphOCRImport`, удалите его. Выберите **File → Import File**, импортируйте `CorelParagraphOCRImport.bas`.
3. Запустите **`Main_ImportPosterOCR`** и выберите JSON в штатном графическом диалоге. Можно вставить полный путь.
4. Проверьте расположение, шрифты, мелкие фрагменты и переполнение, затем сохраните новый CDR.

Дополнительный вход `Main_ImportPosterOCRFromPath(jsonPath)` принимает путь из внешнего скрипта, если в будущем понадобится drag-and-drop. Самостоятельный файловый drag-and-drop на значок макроса в CorelDRAW **не реализован**.

## Проверки и ограничения

Файлы проверены программно на структуру JSON, координаты, кодировку CP1251 и совпадение байтов исходника VBA. **Компиляция, запуск, реальные шрифты и переполнение в CorelDRAW 2026 не проверялись**. Устаревшие формулировки на исходных плакатах сохранены без редактирования по смыслу; перед публикацией технические и медицинские инструкции нужно сверить с актуальными требованиями.
