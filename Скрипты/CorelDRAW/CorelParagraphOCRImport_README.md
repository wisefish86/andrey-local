# Импорт OCR-плакатов в CorelDRAW 2026

Новый независимый модуль: **CorelParagraphOCRImport.bas** (Windows-1251 / CP1251), исходник для чтения и контроля версий: **CorelParagraphOCRImport.utf8.txt** (UTF-8).

**Запуск:** в редакторе VBA CorelDRAW выберите File → Import File → `CorelParagraphOCRImport.bas`, затем запустите `Main_ImportPosterOCR`, выберите подготовленный `posters_ocr_corel.json`.

**Результат:** новый двухстраничный документ с редактируемыми абзацными текстовыми рамками по координатам в JSON. Открытые файлы не изменяются. В исходном JSON — массивы `pages` и `blocks`; блоки содержат `id`, `page`, `x_px`, `y_px`, `width_px`, `height_px`, `font_pt`, `role`, `text` и `needs_review`. Единицы документа — мм, координаты исходного изображения — пиксели от левого верхнего угла каждой страницы.

Макрос читает JSON в UTF-8 встроенным минимальным парсером VBA (без внешней библиотеки), сохраняет текст дословно, не создаёт изображения и фон. Для читаемости без фона текст чёрный Arial, заголовки жирным. Переносы строк остаются внутри текстовых рамок.

**Перед публикацией:** вручную сверить OCR с картинкой, исправить переполнения и проверить старые медицинские рекомендации плаката; точность исходной растровой картинки не гарантирует безошибочность текста.

**Проверено:** структура JSON, размеры и диапазоны координат 95 блоков, соответствие байтов CP1251-версии исходнику и GitHub blob SHA. **Не проверено:** фактическая компиляция, импорт и визуальная вёрстка в CorelDRAW 2026.
