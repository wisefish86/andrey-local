# Скрипты Andrey Local

Три основные категории: **Личные**, **Пение**, **Работа**. Служебные папки: **Система ярлыков** (единый генератор) и **Система GitHub** (синхронизация репозитория).

Принципы:
- Одна задача = одна папка со скриптом, связанными ресурсами и README.md; простые файлы не дробим на искусственные категории.
- Запускаемые BAT называем по действию на русском, например `Запустить резервное копирование настроек.bat`; внутренние PS1/PY/PYW/AHK могут иметь английские имена.
- У PS1 и консольного PY должен быть BAT-запускатель (за исключением вспомогательных вызываемых модулей).
- Локальные ярлыки `- ярлык.lnk` создаются **рядом с BAT, AHK и PYW**, имеют иконку из общего каталога и не перезаписывают пользовательские изменения.
- Папка `Ярлыки/` больше не заполняется генератором — это личная подборка.
- Файлы проекта сохраняют существующие пути, пока перенос не проверен на регрессии; не переставляй исполняемые файлы отдельно от соседних зависимостей.
- При создании нового инструмента добавь краткий README: назначение, что запускать, входные данные, результат и ограничения.
- Входящие исходники для проверки — `inbox/scripts`. После подтверждённого использования переносить в `inbox/Done`, не удалять автоматически.

Смотри README внутри каждой тематической папки и `Система ярлыков/README.md`.
