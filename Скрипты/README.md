# Скрипты — рабочая библиотека

Здесь живут действующие сценарии автоматизации. Для новых скриптов используй `inbox/scripts/`, затем после проверки они попадают в тематическую папку.

- `Личные/` — пользовательские инструменты.
- `Система ярлыков/` — автоматическое создание `.lnk` и сборка иконок.
- Для пользовательских `.ps1` и консольных `.py` по умолчанию нужен удобный BAT-запускатель. Для `.pyw` BAT не обязателен.
- Ярлыки генерируются **только для BAT и PYW** внутри локальной папки `Ярлыки/`.
- Не запускай незнакомые скрипты до разбора. Папки исходного кода не переносить без проверки путей.
