# Сборка PDF-превью

**Запуск:** `PDF-сборщик (перетяни файлы).bat`.

Запускает соседний GUI `PDF-сборщик.pyw` для сборки PDF-превью. Перетаскивай файлы на BAT или его ярлык; результат проверь вручную.

**Ярлык:** после запуска общего генератора появляется рядом с BAT (`- ярлык.lnk`). Его можно скопировать в свою подборку. Существующий изменённый вручную ярлык не перезаписывается.
