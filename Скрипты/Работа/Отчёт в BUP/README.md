# Отчёт в BUP

**Первый этап автоматизации:** открыть существующий ярлык программы и заполнить два поля словом `Шевцов`, после чего нажать Enter.

- `Отчёт в BUP.ahk` — главный скрипт для **AutoHotkey v2**.
- Ярлык `Отчёт в BUP - ярлык.lnk` автоматически создаётся рядом на Windows общим генератором ярлыков. BAT для AHK **не нужен**.

Путь запускаемой программы задан внутри AHK:
`D:\YandexDisk\Проекты\Работа в Компас\- Задачи (рабочие)\- Избранные задачи\- BUP.lnk`.

Для двух стандартных элементов диалога BUP используются `Edit1` и `Edit2`. Скрипт проверяет наличие окна, полей и правильность введённого текста **до Enter**. Если приложение использует нестандартные элементы, скрипт покажет ошибку вместо ненадёжных координат. Проверить работу нужно локально на Windows: скриншота недостаточно, чтобы подтвердить названия элементов управления.

Не публиковать реальные данные из отчётов и персональные файлы в публичный репозиторий.
