# Заказ: начало работы

**Запуск:** `[заказы] 1. Начало работы.bat`.

Запускает `rename.py` для подготовки/переименования материалов заказа. Перетащи входной файл, архив или папку на BAT или ярлык. Проверь результат на тестовых данных.

**Ярлык:** после запуска общего генератора появляется рядом с BAT (`- ярлык.lnk`). Его можно скопировать в свою подборку. Существующий изменённый вручную ярлык не перезаписывается.

## Если перетаскивание ничего не делает

1. Сначала перетащи тестовую папку заказа прямо на `[заказы] 1. Начало работы.bat`, **не на старый ярлык**. BAT показывает ошибки Python и отсутствующих зависимостей и не закрывает окно при ошибке.
2. Если BAT работает, а ярлык нет: проверь в свойствах ярлыка поле «Объект». Оно должно указывать на текущий BAT в этой папке. Старый `.lnk` может хранить абсолютный путь до переноса репозитория. Создай новый ярлык из BAT или удали сломанный старый и запусти `Скрипты/Система ярлыков/Обновить ярлыки.bat`.
3. Для Python нужен `openpyxl`. Данные заказов меняются по правилам `rename.py`, поэтому испытывай сначала на копии заказа.

Файл `rename.py` не изменён этим исправлением: изменён только BAT-запускатель и диагностика.

## Открытие файлов после подготовки заказа

Скрипт не копирует реквизиты заказа в буфер обмена и не открывает автоматически исходный Excel или `- Позиции заказа.txt`. Оба формата продолжают использоваться для чтения/создания данных, а `- Позиции заказа.json` сохраняется для CorelDRAW. CDR открывается как прежде; файл email открывается при нескольких адресах, а также открывается папка заказа или вложений.
