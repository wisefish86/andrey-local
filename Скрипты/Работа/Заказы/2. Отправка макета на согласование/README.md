# Заказ: согласование

**Запуск:** `[заказы] 2. Отправка макета на согласование.bat`.

Запускает `send_for_approval.py` для материалов согласования. Перетащи папку заказа на BAT или ярлык. Проверь параметры перед отправкой.

**Ярлык:** после запуска общего генератора появляется рядом с BAT (`- ярлык.lnk`). Его можно скопировать в свою подборку. Существующий изменённый вручную ярлык не перезаписывается.
