# Заказ: подготовка к печати

**Запуск:** `[заказы] 3. Подготовка к печати.bat`.

Запускает `prepare_print.py` для подготовки файлов к печати. Проверь состав и результаты перед передачей в производство.

**Ярлык:** после запуска общего генератора появляется рядом с BAT (`- ярлык.lnk`). Его можно скопировать в свою подборку. Существующий изменённый вручную ярлык не перезаписывается.
