# Заказ: очистка

**Запуск:** `[заказы] 5. Удаление лишнего.bat`.

Запускает `cleanup_order.py`, который может удалять файлы. Выполняй только после проверки на тестовой копии и резервирования исходных материалов.

**Ярлык:** после запуска общего генератора появляется рядом с BAT (`- ярлык.lnk`). Его можно скопировать в свою подборку. Существующий изменённый вручную ярлык не перезаписывается.
