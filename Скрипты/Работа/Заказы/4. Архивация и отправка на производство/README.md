# Архивирование заказа

Запуск: `[заказы] 4. Архивация и отправка на производство.bat`.

BAT вызывает `archive.py` для подготовки архива и передачи материалов на производство. Перед рабочим запуском проверь файлы и путь назначения на тестовом заказе.

Ярлык создаётся рядом с BAT генератором системы ярлыков.
