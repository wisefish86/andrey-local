# Заказы — пять последовательных операций

В каждой пронумерованной папке лежат BAT для запуска/перетаскивания и соответствующий Python-код.

1. `1. Начало работы/` — подготовка и переименование исходных материалов; перетащи файл, архив или папку на BAT.
2. `2. Отправка макета на согласование/` — создание материалов для согласования.
3. `3. Подготовка к печати/` — подготовка печатных файлов.
4. `4. Архивация и отправка на производство/` — создание и отправка архива.
5. `5. Удаление лишнего/` — удаление временных файлов, проверять на тестовой копии заказа.

Запускай BAT, а не PY напрямую. Генератор помещает ярлык рядом с каждым BAT, и перетаскивание на ярлык передаёт путь запускаемому сценарию. Рабочие папки не менялись, чтобы сохранить относительные пути. 

## Единый файл данных заказа (новый формат)

Новые заказы используют `- Данные заказа.json` в корне папки заказа. В нём хранятся `order_number`, `order_date`, `client`, `manager`, `emails`, `items`; скрипт отправки на согласование добавляет `approval.last_sent_at`, `approval.send_count` и `approval.history`. Отдельные `- Позиции заказа.txt` и `- Emails для согласования.txt` больше не создаются. Подпапка Data не используется.

Скрипты этапов 2 и 4 сначала ищут новый JSON, а если его нет, читают старые `- Позиции заказа.json` и `- Emails для согласования.txt`. Старые заказы автоматически не переписываются. При наличии нового JSON адреса берутся только из него, чтобы не смешивать источники.

**Важно:** внешние макросы CorelDRAW, читающие старое имя `- Позиции заказа.json`, необходимо отдельно проверить и адаптировать. Не удаляй старые файлы до такой проверки.
