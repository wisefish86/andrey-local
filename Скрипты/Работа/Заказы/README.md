# Заказы — пять последовательных операций

В каждой пронумерованной папке лежат BAT для запуска/перетаскивания и соответствующий Python-код.

1. `1. Начало работы/` — подготовка и переименование исходных материалов; перетащи файл, архив или папку на BAT.
2. `2. Отправка макета на согласование/` — создание материалов для согласования.
3. `3. Подготовка к печати/` — подготовка печатных файлов.
4. `4. Архивация и отправка на производство/` — создание и отправка архива.
5. `5. Удаление лишнего/` — удаление временных файлов, проверять на тестовой копии заказа.

Запускай BAT, а не PY напрямую. Генератор помещает ярлык рядом с каждым BAT, и перетаскивание на ярлык передаёт путь запускаемому сценарию. Рабочие папки не менялись, чтобы сохранить относительные пути.
