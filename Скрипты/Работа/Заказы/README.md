# Обработка заказов — пять этапов

Все пять этапов находятся **в одной папке**, каждый вместе с собственным BAT-запускателем и Python-скриптом:

1. **Начало работы** — переименование и подготовка входящих файлов. Перетащи файл, архив или папку на BAT.
2. **Отправка макета на согласование** — работа с папкой заказа. Перетащи папку на BAT.
3. **Подготовка к печати** — подготовка файлов из папки заказа.
4. **Архивация и отправка на производство** — архивирование и отправка.
5. **Удаление лишнего** — операция удаления; использовать особенно осторожно и только с резервной копией заказа.

Рабочие файлы в подпапках намеренно не отделены друг от друга: BAT вызывает соседний `.py` через `%~dp0`. Ярлыки будут созданы генератором в локальной папке `Ярлыки/Скрипты/Работа/Заказы/`.

**Статус:** исходные файлы перенесены с сохранением байтов; запуск на Windows и проверка реального рабочего процесса ещё не выполнялись. Для пунктов 4 и 5 сначала проверь на тестовом заказе, чтобы избежать потери данных.
