# Очистка CSV

**Запуск:** `run_csv_cleaner.bat`.

Открывает Python GUI `csv_cleaner_gui.py`; настройки находятся в `presets.json`. Перед обработкой проверь, какие столбцы будут удалены, и сохрани исходный CSV.

**Ярлык:** после запуска общего генератора появляется рядом с BAT (`- ярлык.lnk`). Его можно скопировать в свою подборку. Существующий изменённый вручную ярлык не перезаписывается.
