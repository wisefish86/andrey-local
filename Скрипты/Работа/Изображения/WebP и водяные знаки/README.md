# Конвертация в WebP и водяной знак

**Запуск:** `[скрипт] Конвертировать в WebP 75%.bat` или `[скрипт] Добавление водяного знака и конв. в WebP 75%.bat`.

Конвертирует изображения в WebP с качеством 75%; второй BAT использует `!watermark.png`. Есть зависимость от внешней утилиты конвертации — проверь её наличие перед запуском.

**Ярлык:** после запуска общего генератора появляется рядом с BAT (`- ярлык.lnk`). Его можно скопировать в свою подборку. Существующий изменённый вручную ярлык не перезаписывается.
