# Рабочие инструменты

- `Заказы/` — единая цепочка пяти этапов от получения материалов до производства.
- `PDF-превью/` — сборка PDF с помощью BAT и PYW.
- `Изображения/WebP и водяные знаки/` — обработка изображений с использованием внешнего nconvert; требуется проверить его установку.
- `CSV/Очистка столбцов/` — очистка CSV, Python и файл настроек.

Новую партию скриптов сначала загружай в `inbox/Разобрать скрипты/` или `inbox/scripts/`. Настоящие ярлыки создаются для BAT/PYW после синхронизации.
