REPERTOIRE CONVERTER v11

Рядом со скриптом:
songs.csv
replacements.json

Запуск:
start.bat

songs.js содержит:
- полную копию replacements.json в config;
- песни;
- группы;
- цвета;
- веса;
- правила замен.

Сайт работает только с songs.js.

Дубли:
Исполнитель + Название.
Рейтинг берется максимальный.
Теги объединяются.

Хит:
rating >= 242.
