# Репертуар для сайта

**Запуск:** `start.bat`.

Использует `converter.py`, `songs.csv`, `replacements.json` и `songs.js` для преобразования данных репертуара. HTML-представление находится в `Репертуар на сайт в HTML/`. При изменении формата проверяй итоговый JS.

**Ярлык:** после запуска общего генератора появляется рядом с BAT (`- ярлык.lnk`). Его можно скопировать в свою подборку. Существующий изменённый вручную ярлык не перезаписывается.
