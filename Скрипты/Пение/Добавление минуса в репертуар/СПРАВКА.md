# Справка — Добавление минуса в репертуар

## Название и Title

Title собирается автоматически из языка, названия, тональности и F/S.

- `⚪️` — русский;
- `🔴` — английский или другой иностранный;
- `✂️` — минус нужно укоротить.

Пример:

`✂️ ⚪️ WAKE UP! [-2] [S]`

Язык выбирается один и находится в блоке **«Песня и файл»**, потому что он напрямую формирует Title.

Кнопки **«По шаблону»** есть у **«Название»**, **Title**, **«Файл минуса»** и **«Папка песни»**. Они подсвечиваются фиолетовым, если значение отличается от шаблона, и возвращаются к обычному цвету после исправления. Для свободного «Названия» шаблон проверяет только добавление или удаление обозначения выбранной версии — текст песни он не угадывает и не переписывает.

## Тематические песни

**Статус (ТXXX:OCCASION)** отвечает за готовность: База, Рабочие, Тестирую, Повторить, Выучить и т. д. **Тематика — независимый признак**, её нельзя добавлять в статусы.

- В поле **«Аудитория / формат»** выбери **«Тематическая»** (ID3 `TIT1: а-Ситуац`).
- В поле **«Ситуации / тематика»** добавь уточнения: «23 февраля», «Патриотическая», «Новый год» и т. п. — одна песня может иметь несколько.
- В папке Syncthing `Минусы по категориям` тематические песни с рабочим статусом автоматически оказываются в `06 Тематические`, а не в папке их статуса. **Сам статус в MP3 не изменяется.**
- Песни со статусами **Запас** и **Версии** по-прежнему не копируются. Для сайта используются исходные независимые теги, а не имя папки Syncthing.
- Изменение признака «Тематическая» при сохранении MP3 также меняет итоговую категорию, поэтому главное приложение предложит запустить оба перескана.

Имя папки, значение тега и режим работы хранятся в `Распределение минусов/config.json → thematic_routing`.

## Тональность

Актуальные значения:

`— / -3 / -2 / -1 / N / +1 / +2 / +3`

- `—` — маркер тональности не нужен;
- `N` — тональность неизвестна.

`0` не используется.

## F / S

- `F` — полная версия;
- `S` — сокращённая версия.

## Примечание после ֎

Пример:

`Название [-2] _____ Исполнитель ֎ мз, buy, +click.mp3`

| Сокращение | Значение |
|---|---|
| `инст` | Инструментал |
| `оф.инст` | Официальный инструментал |
| `buy` | Куплено |
| `buy-J` | Куплено в «Жадина» |
| `+click` | Добавлено вступление |
| `+такт` | Добавлены звуки такта |
| `мз` | Мастер-запись |
| `ориг` | Оригинал |
| `+Б` | С бэк-вокалом |
| `-Б` | Без бэк-вокала |
| `мБ` | Мой бэк |
| `$` | Старый маркер LUFS; больше не используется |

## Год песни

В **«Теги и подбор → Поиск и сайт»** рядом с годом есть кнопка **«🔎 Найти год в Google»**.

Запрос собирается из исполнителя и чистого названия песни и ищет дату выхода / год релиза.

## Альбом

`ALBUM = минусы` — фиксированное значение. Оно показывается серым и не редактируется из GUI.

## Инструменты репертуара

В нижнем сворачиваемом блоке доступны массовые и редкие операции:

- перескан для Singer Andrey;
- миграция плюсов на FTP;
- список проблемных папок;
- импорт тегов из CSV;
- исправление лирики;
- распределение минусов;
- подготовка текущего MP3 для фонотеки;
- открытие общей папки инструментов.

Подробности — в `Инструменты репертуара/README.md`.
