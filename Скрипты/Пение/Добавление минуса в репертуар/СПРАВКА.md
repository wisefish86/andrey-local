# Обозначения в примечании

Эти сокращения используются **после символа `֎`** в имени минусовки.

Пример:

```
Название [-2] _____ Исполнитель ֎ мз, buy, +click.mp3
```

| Сокращение | Значение | Комментарий |
|---|---|---|
| `инст` | Инструментал | |
| `оф.инст` | Официальный инструментал | |
| `buy` | Куплено | |
| `buy-J` | Куплено в «Жадина» | |
| `+click` | Добавлено вступление | |
| `+такт` | Добавлены звуки такта | |
| `мз` | Мастер-запись | |
| `ориг` | Оригинал | |
| `+Б` | С бэк-вокалом | |
| `-Б` | Без бэк-вокала | |
| `мБ` | Мой бэк | |
| `$` | Нормализовано через LUFS | **Больше не используется** |

## Тональность

Тональность выбирается отдельно в программе:

- `N` — неизвестна;
- `-3 … -1` — ниже оригинальной;
- `0` — без транспонирования;
- `+1 … +3` — выше оригинальной.

## Название (Title)

Значок перед названием формируется по языку:

- `⚪️` — русский;
- `🔴` — иностранный;
- `⚪️🔴` — в песне есть и русский, и иностранный язык.

Title можно исправить вручную. Кнопка **«По шаблону»** вернёт автоматическое название.
