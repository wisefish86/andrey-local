# Инструменты репертуара

Это служебный контейнер для операций, которые относятся ко всему репертуару и запускаются реже, чем обычное добавление одного минуса.

## Актуальные инструменты

### Пересканировать репертуар для Singer Andrey

`Пересканировать репертуар для Singer Andrey.bat`

Сканирует MP3-минусовки с маркером `֎` непосредственно из `paths.library_root`, читает ID3 и создаёт нейтральный:

`../data/site/repertoire.json`

JSON не привязан к конкретной верстке сайта. Будущая страница Singer Andrey должна использовать его как источник данных.

В экспорт входят:
- Artist, Название, Title, Album, Year;
- BPM и ReplayGain;
- WOAS / ссылка на плюс;
- все управляемые поля из `config.json → fields`;
- признак наличия текста;
- схема полей и варианты значений из текущего `config.json`.

Полный текст песни по умолчанию не публикуется (`site_export.include_lyrics=false`).

### Миграция плюсов

- `Миграция плюсов - ПРОВЕРКА.bat` — dry-run;
- `Миграция плюсов - ПРИМЕНИТЬ.bat` — загрузка плюсов на FTP и запись WOAS.

## Legacy

`legacy-old-site/` — замороженная предыдущая система `songs.csv → converter.py → songs.js → HTML`.

Она сохранена только как референс. Не использовать её как актуальный источник данных или архитектуру нового Singer Andrey.
