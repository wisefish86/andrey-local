# Инструменты репертуара

Единый контейнер для редких и массовых операций над минусовками.

## Структура

- `Сайт Singer Andrey/` — перескан MP3/ID3 в `data/site/repertoire.json`; внутри лежит `legacy-old-site/` как архив старого сайта.
- `Миграция плюсов/` — dry-run и пакетная загрузка плюсов с записью WOAS.
- `Обновление тегов/` — импорт тегов из CSV.
- `Исправление лирики/` — проверка/исправление встроенной лирики.
- `Распределение минусов/` — распределение папок для Syncthing.
- `Подготовка фонотеки/` — подготовка выбранных MP3.
- `Нормализация аудио видео/` — старый drag-and-drop инструмент ffmpeg.

## Singer Andrey

Запуск:

`Сайт Singer Andrey/Пересканировать репертуар для Singer Andrey.bat`

Сканер читает только MP3-минусовки с `֎` из `paths.library_root`, пропуская Files / Additi0ns / Additions / Editions / staging.

Создаётся:

`../../data/site/repertoire.json`

Экспорт не меняет MP3 и не зависит от конкретной верстки сайта.

## Миграция плюсов

- `Миграция плюсов/Миграция плюсов - ПРОВЕРКА.bat` — dry-run;
- `Миграция плюсов/Миграция плюсов - ПРИМЕНИТЬ.bat` — реальная загрузка и WOAS.

При dry-run дополнительно всегда создаётся:

`../../data/migration_plus_links/ПРОБЛЕМНЫЕ ПАПКИ.txt`

В него попадают папки без плюса, с несколькими кандидатами, с коллизией slug или ошибкой чтения тегов.

## GUI-комбайн

Все основные операции можно запускать из финального блока **«Инструменты репертуара»** основной программы.

Для инструментов, рассчитанных на drag-and-drop произвольных файлов, есть кнопка **«Открыть все инструменты»**.
