# Исправление лирики

**Запуск:** `[скрипт] Исправить ошибки со встроенной лирикой.bat`.

Открывает Python-инструмент `mp3_lyrics_gui.py` для работы со встроенными текстами аудиофайлов. Проверяй результат на копии MP3.

**Ярлык:** после запуска общего генератора появляется рядом с BAT (`- ярлык.lnk`). Его можно скопировать в свою подборку. Существующий изменённый вручную ярлык не перезаписывается.
