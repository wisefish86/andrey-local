# Плейлист по заявке посетителя

**Источник:** локальный `data/repertoire.json` и экспорт `repertoire.public.json` версии 6. Публичная версия содержит `playlist_variants` со всеми вариантами одной песни и их относительными путями. Полный локальный путь формируется при отправке M3U8 владельцу из общего корня фонотеки.

## Поведение

- Посетитель выбирает песню один раз (`song_id`).
- Генератор «Создать плейлист из заявки.py» добавляет **все MP3-версии**
  этой песни из локального каталога, включая не публикуемые на сайте
  технические версии (например «Запас» или «Версии»).
- Порядок песен из заявки сохраняется; порядок версий — из локального каталога.
- Для каждой версии в M3U8 записываются абсолютный путь, длительность и
  собственный `TIT2` (где +Б, -Б, тональность и т. п.).
- Одинаковые локальные пути не дублируются.
- Если хотя бы один выбранный song_id или его минусовка отсутствует,
  вместо неполного M3U8 выдаётся ошибка. Обновите каталог и повторите.
- MP3 и ID3-теги не изменяются. M3U8 создаётся как UTF-8 с BOM для MusicBee.

## Генерация

Сохраните JSON с массивом выбранных song_id:

`{"song_ids":["0123456789abcdef","fedcba9876543210"]}`

Затем запустите Python, подставив свои локальные пути:

```cmd
python "Создать плейлист из заявки.py" "selection.json" --catalog "data\repertoire.json" --root "D:\YandexDisk\Проекты\Пение\Минусы\1. Основной репертуар" --output "Заявка.m3u8"
```

Команду выполняйте из папки «Сайт Singer Andrey» на том компьютере,
где находится библиотека MP3. Входной selection.json пока готовится отдельно.

## Автоматическая отправка M3U8 — код подготовлен, запуск на сервере ещё не выполнен

Код `singer-request` в репозитории сайта теперь создаёт M3U8 по версии 6 каталога и пытается отправить его владельцу вложением при создании и изменении заявки. Чтобы включить на действующем сайте, нужен актуальный опубликованный каталог, настройка `SINGER_MP3_ROOT` в Edge Function и отдельный деплой функции. Эти production-операции пока не выполнены. Локальный резервный генератор по-прежнему работает отдельно.
