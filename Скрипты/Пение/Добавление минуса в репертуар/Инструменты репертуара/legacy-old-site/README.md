# Legacy: старый сайт репертуара

Замороженный снимок прежней системы репертуара.

Схема:
`songs.csv → converter.py + replacements.json → songs.js → html/`.

Эта ветка сохранена только для сверки старого поведения и дизайна. Актуальный экспорт строится непосредственно из MP3/ID3 через соседний скрипт `Пересканировать репертуар для Singer Andrey.py`.
