# Аудит ID3

Безопасный экспорт метаданных репертуарных MP3 в JSON без текстов песен.

## Запуск

Экспортировать все ID3 в JSON.bat

Скрипт берёт корневую папку из ../../config.json → paths.library_root и рекурсивно берёт все MP3 с символом ֎. По умолчанию никакие подпапки не исключаются — это полный аудит. Для специальной сверки с публичным экспортом можно вручную запустить Python с параметром --use-site-excludes.

MP3 не изменяются. USLT, SYLT, APIC, GEOB и PRIV остаются в исходных MP3, но не включаются в JSON и не сериализуются. Таким образом обложки и данные Adobe XMP не раздувают отчёт.

Текущие ссылки на плюсы WOAS сохраняются в JSON без изменений.

## Что попадает в JSON

Для каждого файла сохраняются:

- абсолютный и относительный путь;
- имя, размер и время изменения файла;
- технические параметры MP3, которые отдаёт Mutagen;
- удобная сводка текущих рабочих тегов: TPE1, MVNM, TIT2, TALB, TPE2, TDRC, TCON, TMOO, TIT1, TXXX:OCCASION, TBPM, WOAS, рейтинг, ReplayGain;
- все распознанные ID3-фреймы, **кроме USLT (обычная лирика) и SYLT (синхронная лирика)**;
- атрибуты каждого фрейма;
- бинарные значения (APIC, PRIV и подобные) в base64, чтобы аудит не терял содержимое неизвестных старых тегов;
- ошибки чтения по конкретным файлам;
- агрегированная статистика типов ID3-фреймов.

Результат создаётся в:

data/id3_full_export_YYYY-MM-DD_HH-MM-SS.json

Локальная папка `Аудит ID3/data/` исключена из Git. Ранее созданные отчёты в общей `../../data/id3_audit/` автоматически не удаляются.

## Важно

Этот JSON — снимок для анализа, а не файл, который сейчас автоматически пишется обратно в MP3.

Следующий этап после реального экспорта:

1. посмотреть, какие фреймы фактически встречаются;
2. определить канонический белый список и правила миграции;
3. отдельно сделать безопасный JSON → ID3 импорт с dry-run, backup, проверкой после записи и остановкой при первой ошибке.

Существующий Обновление тегов/src/import_tags.py уже содержит полезную безопасную механику preflight / backup / verify / rollback. Новый импорт нужно строить на ней и на общем _common/id3_io.py, а не писать третий независимый механизм записи.

## Очистка устаревших тегов (без дополнительного резервного копирования)

- `Проверить очистку.bat` — только просмотр; MP3 не меняются.
- `Применить очистку.bat` — удаляет `PRIV:XMP`, `WOAF`, `WOAR`, `WXXX`, `WCOP`, `TCOP`, `TOPE`, `TSSE`, `GEOB`, `TIT3`, `TKEY`, `TCMP`, `TDEN`, `TENC` из MP3 с маркером `֎` рекурсивно в основной фонотеке.
- **Сохраняет** `WOAS` (ссылки Singer Andrey), `APIC` (обложки), `USLT`/`SYLT` (лирику), `POPM`, ReplayGain и все рабочие теги. `PRIV` других владельцев не трогает.
- Отчёт создаётся в `Аудит ID3/data/cleanup_preview_*.json` или `Аудит ID3/data/cleanup_apply_*.json` (в папке текущего инструмента).
- Дополнительную копию скрипт не создаёт: перед запуском применения убедиться, что собственный ZIP-архив фонотеки сохранён и доступен.
- При ошибке обработки применение останавливается на проблемном файле. Отдельной функции отката нет.
