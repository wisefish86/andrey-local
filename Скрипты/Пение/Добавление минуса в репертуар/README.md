# Добавление минуса в репертуар

Графическая Windows-программа для одного MP3 за раз.

## Запуск

Запускай:

`Добавить минус в репертуар.pyw`

После обычной синхронизации система ярлыков создаст рядом ярлык на этот PYW. Отдельный BAT не нужен.

На первом запуске, если нет `PySide6` или `mutagen`, программа предложит установить их через pip.

## Основной сценарий

1. Перетащи MP3-минусовку в окно или выбери файл.
2. Программа читает существующие ID3-теги.
3. Заполни/измени теги через понятные списки.
4. При необходимости поправь исполнителя, чистое название, Title, год, источник, тональность и сведения после `֎`.
5. Программа показывает новое имя MP3 и имя папки.
6. Нажми **«Сохранить теги и файл»**.
7. Теги записываются через Mutagen и сразу перечитываются для проверки.
8. После успешной проверки файл переименовывается.
9. Если песня находится внутри:
   `D:\YandexDisk\Проекты\Пение\Минусы\1. Основной репертуар\- - Добавляю в репертуар`
   можно одновременно переименовать и перенести всю папку песни в основной репертуар.

Автоперенос не включается для MP3, открытого из произвольной папки.

## Что редактируется

### Песня и файл
- Исполнитель → TPE1
- Название → MVNM
- Название (Title) → TIT2; по шаблону получает языковой значок `⚪️`, `🔴` или `⚪️🔴`
- Год → TDRC
- Ссылка на плюс → WOAS; это прямой URL на плюсовую/вокальную версию для будущего воспроизведения на сайте
- Альбом автоматически = `минусы`
- тональность — выпадающий список `N, -3, -2, -1, 0, +1, +2, +3`, где `N` = неизвестна
- Примечание — текст после `֎` в имени MP3
- имя MP3 и имя папки генерируются по шаблону, но допускают ручную правку.

### Выступление
- роль в блоке B → TPE2;
- статус G → TXXX:OCCASION;
- сложность SL → TMOO;
- знание текста Z → TIT1;
- характер/энергия K → TCON.

### Поиск и сайт
В TIT1 хранятся:
- аудитория A;
- узнаваемость;
- настроение N;
- язык — **multi-select**, можно одновременно выбрать русский и английский/иностранный;
- эпоха;
- ситуации S.

Языковой значок в Title:
- русский → `⚪️ Название`;
- иностранный → `🔴 Название`;
- русский + иностранный → `⚪️🔴 Название`.

Title можно редактировать вручную; кнопка «По шаблону» возвращает автогенерацию.

### Дополнительно
В TIT1:
- ресторан/площадка R;
- вокальные особенности.

Неизвестные значения TIT1 не удаляются молча: программа сохраняет их и показывает предупреждение.

## Конфигурация

`config.json` — источник вариантов списков, путей и шаблонов.

Изменение вариантов выпадающих списков не требует правки Python.

Текущие пути:
- staging: `D:\YandexDisk\Проекты\Пение\Минусы\1. Основной репертуар\- - Добавляю в репертуар`;
- основной репертуар: `D:\YandexDisk\Проекты\Пение\Минусы\1. Основной репертуар`.

Шаблон папки:
`{clean_title} _____ {artist}`

Шаблон MP3:
`{clean_title} [тональность] _____ {artist} ֎ сведения.mp3`

Если имя MP3 или папки исправлено вручную, автогенерация его больше не перезаписывает до нажатия «По шаблону».

## Безопасность

- существующий файл/папка не перезаписываются;
- запись тегов проверяется повторным чтением;
- при ошибке после записи программа пытается восстановить исходные управляемые теги;
- перенос папки разрешён автоматически только из staging-папки;
- все операции пишутся в локальный `data/operations.jsonl` (он не нужен в GitHub).

## Архитектура

- `Добавить минус в репертуар.pyw` — тихий GUI-запуск без консоли;
- `src/app.py` — PySide6 UI и сценарий обработки;
- `config.json` — поля/варианты/пути;
- `../_common/id3_io.py` — общие операции Mutagen/ID3 для инструментов пения.

Первая версия намеренно не считает ReplayGain, не редактирует lyrics/SYLT, не определяет автоматически сложность/знание текста и не работает пакетно.


## Значения по умолчанию

Для нового/неразмеченного MP3 все смысловые поля стартуют как «Не заполнено» (`#`), кроме:

- **Статус = `г-5-Выучить`**.

Ресторан и вокальные особенности по умолчанию пустые. Никакая аудитория/энергия/роль не подставляется автоматически.

## Справка обозначений

Файл `СПРАВКА.md` содержит таблицу сокращений после `֎`: `мз`, `buy`, `buy-J`, `+click`, `+такт`, `ориг`, `+Б`, `-Б`, `мБ` и др.

В GUI рядом с полем «Примечание» есть кнопка `ⓘ`, которая показывает этот Markdown прямо во встроенном окне. Внешний браузер или отдельный HTML не нужен.
