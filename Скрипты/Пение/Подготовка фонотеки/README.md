# Подготовка фонотеки

**Запуск:** `[скрипт] Подготовка треков для фонотеки.bat`.

Запускает соседний PowerShell по подготовке музыкальных треков. Перед массовой обработкой проверь исходные и целевые каталоги.

**Ярлык:** после запуска общего генератора появляется рядом с BAT (`- ярлык.lnk`). Его можно скопировать в свою подборку. Существующий изменённый вручную ярлык не перезаписывается.
