# Подготовка фонотеки — переименование треков

## Что делает
Это инструмент для приведения НАЗВАНИЙ музыкальных файлов к единому виду. Он переименовывает выбранные файлы на месте, но не изменяет звук, громкость или ID3-теги.

По действующим правилам:
- убирает одинарную или обратную кавычку в начале имени;
- заменяет длинные тире обычным дефисом и «ё» на «е»;
- приводит feat. и ft. к символу &;
- удаляет приписку (promodj.com), лишние пробелы и поправляет пунктуацию;
- добавляет знак ℗ в конце названия перед расширением, если его ещё нет.

## Как запустить
1. Сначала сделай пробу на КОПИЯХ нескольких треков: обычный запуск переименовывает оригиналы.
2. Выдели треки в Проводнике и перетащи их на [скрипт] Подготовка треков для фонотеки.bat.
3. BAT создаст временный список выбранных путей и передаст его одноимённому PowerShell-скрипту.
4. PS1 применит правила из одноимённого TXT, покажет результат и запишет журнал LOG рядом со скриптом.

Простой двойной щелчок по BAT без перетаскивания файлов покажет подсказку. Ярлык «- ярлык.lnk» предназначен для удобного доступа; для передачи файлов используй BAT.

## Файлы в папке
- BAT — запускатель для перетаскивания треков.
- PS1 — сам переименователь. При прямом запуске требует параметр -FileListPath (UTF-8-файл, один путь на строку).
- TXT — правила переименования: PREFIX, SUFFIX, REPLACE, REGEX, ADD. Их можно менять отдельно от кода.
- LNK — ярлык, создаваемый или обновляемый системой ярлыков.
- LOG — журнал последнего запуска; при новом запуске предыдущий журнал удаляется.

## Ограничения
- В PS1 есть режим предварительного просмотра -WhatIfMode, но обычный BAT его НЕ включает.
- При совпадении нового имени с уже существующим файл пропускается.
- Файлы остаются в исходных папках; это не сортировка, не конвертация и не изменение тегов.
- BAT, PS1 и TXT должны оставаться рядом: они связаны относительными путями.
