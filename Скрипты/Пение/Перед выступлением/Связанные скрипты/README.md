# Перед выступлением

Главный запускатель: `[скрипт] Перед пением.bat`; основной PowerShell: `[скрипт] Перед пением.ps1`. Ярлык к BAT расположен рядом.

Вспомогательные действия находятся в этой папке и запускаются главным сценарием:
- Удаление символа `֎` из названий файлов в `Files` и `Additi0ns` (отдельное окно, которое ожидает Enter).
- Панель громкости AutoHotkey — непосредственно через `.ahk`, BAT не нужен.
- Показать IPv4 — отдельное окно с адресами, закрывается вручную.

Остальные команды основного PS1 (завершение процессов, запуск параметров Windows, лупы и Anytype) сохранены. Дополнительный BAT «Удалить из файлов внутри подпапок» оставлен как совместимый запускатель операции удаления символа (ранее ошибочно повторно запускал главный сценарий).

При перемещении и переименовании файлов старые Windows-ярлыки могут сохранить прежние абсолютные пути. Генератор ярлыков на Windows создаёт недостающие `.lnk` рядом с BAT/AHK, сохраняя уже существующие.
