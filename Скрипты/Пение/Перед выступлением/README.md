# Подготовка к выступлению

**Запуск:** `[скрипт] Перед пением.bat`.

В папке также находятся отдельные действия по обработке имён файлов и панель громкости (.ahk и BAT) рядом с основным запускателем, а также подпапка с сетевым инструментом. Поскольку PowerShell может менять окружение, изучи конкретный PS1 перед запуском.

**Ярлык:** после запуска общего генератора появляется рядом с BAT (`- ярлык.lnk`). Его можно скопировать в свою подборку. Существующий изменённый вручную ярлык не перезаписывается.
