# Обновление музыкальных тегов

Основной Python-файл: `update_tags.py`. Список изменений: `update_tags.csv`.

**Запускай через BAT с понятным названием:**
- `Проверить обновление тегов.bat` — проверка изменений без применения; вызывает `check_only.bat`.
- `Применить обновление тегов.bat` — применение изменений; вызывает `apply_all.bat`.

Существующие `check_only.bat`, `apply_all.bat` и `install_mutagen.bat` оставлены для совместимости. Для обработки нужен Python и пакет Mutagen; `check_only.bat` пытается установить Mutagen, если его нет.

**Ярлыки:** генератор `Скрипты/Система ярлыков/Обновить ярлыки.bat` создаёт локальные `.lnk` рядом с BAT. Отдельного ярлыка для `update_tags.py` не нужно. Изменённые вручную ярлыки генератор не перезаписывает.

**Осторожно:** применение изменяет метаданные музыкальных файлов. Сначала используй проверку на тестовых файлах.
