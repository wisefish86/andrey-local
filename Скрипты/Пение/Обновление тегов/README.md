# Обновление музыкальных тегов

Основной Python-файл: `update_tags.py`. Список изменений: `update_tags.csv`.

**Запускай через BAT с понятным названием:**
- `Проверить обновление тегов.bat` — проверка изменений без применения; вызывает `check_only.bat`.
- `Применить обновление тегов.bat` — применение изменений; вызывает `apply_all.bat`.

Существующие `check_only.bat`, `apply_all.bat` и `install_mutagen.bat` оставлены для совместимости. Для обработки нужен Python и пакет Mutagen; `check_only.bat` пытается установить Mutagen, если его нет.

## TagScanner: экспорт для аудита и массовой нормализации

Шаблон `TagScanner - экспорт тегов для нормализации.txt` выгружает в `TrackList.csv` смысловые поля, которые могут потребоваться для анализа и пакетной правки: исполнитель, название, чистое название, альбом, альбом-артист, год, жанр, настроение, группировка/теги, ситуация, комментарий, композитор, автор слов, издатель, рейтинг, WWW, WWW Source и полный путь.

Намеренно не выгружаются Lyrics, BPM, Track и ReplayGain: они не нужны для текущей миграции системы тегов и не должны случайно перезаписываться при обратном импорте.

Перед массовым обратным импортом:
1. Сохрани исходный CSV как резервную копию.
2. Не меняй порядок строк без необходимости.
3. Проверь импорт на небольшой выборке файлов.
4. После импорта проверь несколько файлов в TagScanner/MusicBee до пакетного применения.

**Ярлыки:** генератор `Скрипты/Система ярлыков/Обновить ярлыки.bat` создаёт локальные `.lnk` рядом с BAT. Отдельного ярлыка для `update_tags.py` не нужно. Изменённые вручную ярлыки генератор не перезаписывает.

**Осторожно:** применение изменяет метаданные музыкальных файлов. Сначала используй проверку на тестовых файлах.
