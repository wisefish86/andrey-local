# Обновление музыкальных тегов

**Запуск:** `check_only.bat` — проверка; `apply_all.bat` — применение; `install_mutagen.bat` — установка зависимости.

Работает с `update_tags.csv` через `update_tags.py` и библиотеку Mutagen. Перед массовыми изменениями выполняй проверку; BAT применения меняет метаданные файлов.

**Ярлык:** после запуска общего генератора появляется рядом с BAT (`- ярлык.lnk`). Его можно скопировать в свою подборку. Существующий изменённый вручную ярлык не перезаписывается.
