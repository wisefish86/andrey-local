# Пение

Актуальная структура:

- `Добавление минуса в репертуар/` — основной GUI-комбайн для одного минуса и обслуживания всего репертуара.
- `Добавление минуса в репертуар/Инструменты репертуара/` — все сервисные операции с минусовками: сайт Singer Andrey, FTP-плюсы, импорт тегов, лирика, фонотека, распределение и нормализация.
- `Перед выступлением/` — отдельный этап подготовки к выступлению; намеренно не смешан с обслуживанием файлов репертуара.
- `_common/` — общие Python-модули ID3/FTP; вручную не запускать.

Старые отдельные папки инструментов из корня `Скрипты/Пение` собраны под единым контейнером, чтобы не было нескольких канонических мест.

Пользовательский запуск основной программы:

`Добавление минуса в репертуар/Добавить минус в репертуар.pyw`

Система ярлыков обновляется после GitHub-синхронизации.
