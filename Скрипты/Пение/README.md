# Пение

Сценарии для выступлений, музыкальных файлов и сайта репертуара:
- `Добавление минуса в репертуар/` — графическая программа: MP3 → теги → имя файла/папки → перенос в основной репертуар.
- `Перед выступлением/` — подготовка программ и файлов.
- `Подготовка фонотеки/` и `[дораб.] Распределение минусов/` — организация музыкальных файлов.
- `Обновление тегов/` и `Исправление лирики/` — метаданные MP3.
- `Нормализация аудио видео/` — нормализация громкости.
- `Репертуар для сайта/` — конвертер репертуара и веб-представление.
- `_common/` — общие технические модули, вручную не запускать.

Система ярлыков обновляется автоматически после GitHub-синхронизации через
`Скрипты/Личные/Система ярлыков в andrey-local/Обновить-ярлыки.ps1`.

Для новой программы отдельный BAT не нужен: пользовательский запуск —
`Добавление минуса в репертуар/Добавить минус в репертуар.pyw`
или создаваемый рядом ярлык.

Массовые операции с тегами сначала проверяй в dry-run; одиночная GUI-программа перед переименованием перечитывает и проверяет записанные теги.
