# Система GitHub — синхронизация andrey-local

В этой папке находятся все запускатели и рабочие скрипты синхронизации.

| Файл | Назначение |
|---|---|
| `Синхронизация.ps1` | Ручная синхронизация |
| `Автосинхронизация.ps1` | Фоновая синхронизация |
| `Тихий запуск синхронизации.vbs` | Скрытый запуск фонового задания |
| `Установить автосинхронизацию.bat` | Установка / переустановка задания по двойному щелчку |
| `Установить автосинхронизацию.ps1` | Регистрация задания Windows |
| `Запустить синхронизацию GitHub.bat` | Ручной запуск синхронизации |
| `Запустить автосинхронизацию сейчас.bat` | Разовый запуск автоматического режима |

## Важно после переноса из корня

**Запусти `Установить автосинхронизацию.bat` повторно**. Он перепишет действие существующего задания `AndreyLocal Inbox Auto Sync` на новые пути к `Автосинхронизация.ps1` и `Тихий запуск синхронизации.vbs` в этой папке. Иначе установленное ранее задание продолжит обращаться к удалённым файлам корня.

Репозиторий публичный. Автосинхронизация может создать коммит и отправить новые файлы; не храни в нём пароли, токены и конфиденциальные документы. При конфликтах Git сначала проверяй состояние ветки; не удаляй локальные изменения вслепую.

Рабочие PS1 вычисляют корень репозитория на два уровня выше папки `Система GitHub`. Журнал — `.auto-sync.log` в корне.

Ярлыки `.lnk` для BAT генерируются локально через `Скрипты/Система ярлыков/Обновить ярлыки.bat`. После переезда старые ярлыки с неправильными абсолютными путями могут потребовать пересоздания.


## Порядок ручной синхронизации

Ручная синхронизация теперь всегда сначала интегрирует актуальный `origin/main`.

Если рабочая папка содержит локальные изменения:
1. они временно сохраняются через `git stash -u`;
2. локальная `main` обновляется из `origin/main`;
3. локальные изменения восстанавливаются поверх актуального состояния;
4. только оставшиеся реальные локальные изменения показываются перед публикацией.

Это исключает ситуацию, когда уже сделанные в GitHub переносы/удаления показываются как будто локальные удаления, которые нужно опубликовать.

При конфликте восстановления stash синхронизация останавливается и ничего не отправляет на GitHub.
