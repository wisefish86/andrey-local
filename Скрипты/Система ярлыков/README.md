# Система ярлыков Windows

Создаёт локальную папку `andrey-local/Ярлыки/` со ссылками на запускаемые инструменты.

- `Обновить-ярлыки.ps1` — генератор, запускается автоматически после фоновой Git-синхронизации.
- `Обновить ярлыки.bat` — ручной запуск только для диагностики.
- Обнаруживаются **`.bat` и `.pyw`**, а не `.ps1` или `.py`.
- Подбирает иконки из `Ресурсы/Иконки/ICO/`, правила — `Ресурсы/Иконки/icon-map.json`.
- Устаревшие ярлыки, созданные именно генератором, могут удаляться при переименовании или исключении исходника. Чужие ярлыки не трогает.

**Важно:** это не фоновый запуск самих программ. Каталог `Ярлыки` зависит от путей конкретного ПК и не коммитится в GitHub.
