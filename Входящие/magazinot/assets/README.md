# Done — обработанные входящие

Здесь остаются исходные материалы, которые уже разобраны и у которых проверено место постоянного хранения.

**Done не означает, что файл опубликован на сайте или FTP/OSS.** Содержимое не удаляется автоматически, чтобы было возможно проверить историю и восстановить исходники.

Новые файлы сначала складывай в соответствующую папку `inbox/`, но не в `done/`.
