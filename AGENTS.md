# Правила работы с локальными инструментами

- Этот репозиторий — каноническое место для общих локальных Windows-скриптов пользователя (PowerShell, BAT, Python), утилит, конфигурации и документации. Проектный код хранить в соответствующем проектном репозитории.
- Сначала изучать существующую структуру `Скрипты`, повторно использовать готовые паттерны, не плодить дубли.
- Сохранять исполняемый код и инструкции непосредственно в GitHub, а не ограничиваться ZIP-архивом в чате. Не коммитить личные данные, результаты сканирования, приватные ключи, пароли, токены и другие секреты.
- Предпочитать безопасную проверку без изменений, предварительный просмотр, резервное копирование или откат для инструментов, меняющих файлы пользователя. Проверять созданные файлы и честно отмечать, если запуск на Windows не тестировался.
- После успешных изменений в GitHub всегда завершать ответ пользователю напоминанием **«Синхронизируй GitHub с компьютером»**. В репозитории есть штатный `Синхронизация.bat`.
- Канонический долгосрочный контекст и проектные решения хранятся в Notion («Система работы с GPT»), а код — здесь.
- Файлы из `inbox/` переносить в `inbox/done/` только после подтверждённого использования и завершения всех требуемых для задачи переносов/публикаций/деплоя. Неопределённые или частично обработанные файлы не трогать; подробный единый регламент хранится в `inbox/README.md`.
