# Репертуар Андрея Шевцова --- инструкция по работе с сайтом

## Структура файлов

В папке сайта находятся:

-   `index.html` --- основная HTML-страница.
-   `styles.css` --- оформление и адаптация под мобильные устройства.
-   `app.js` --- логика фильтров, выбора песен, отправки списка.
-   `songs.js` --- база репертуара, теги, веса, цвета и настройки.

------------------------------------------------------------------------

## Обновление репертуара

Основной файл для обновления песен:

`songs.js`

Он создается автоматически конвертером из CSV.

После обновления базы достаточно заменить только `songs.js` на сервере.

------------------------------------------------------------------------

## Логика тегов

Все теги находятся внутри:

`window.REPERTOIRE.config`

Используются 3 группы:

1.  Язык
2.  Ситуация
3.  Жанр

Порядок отображения определяется весом группы.

Пример:

``` json
"language": {
  "weight": 100
}
```

Чем больше вес --- тем выше группа.

------------------------------------------------------------------------

## Вес тегов

Каждый тег имеет свой вес:

``` json
"танцы": {
  "group": "situation",
  "weight": 90
}
```

Сортировка:

1.  Вес группы.
2.  Вес конкретного тега.
3.  Количество песен.

------------------------------------------------------------------------

## Цвета тегов

Цвета задаются в группах:

``` json
"color": "rgba(255,170,70,0.20)"
```

Так как сайт выполнен в темной теме, рекомендуется использовать:

-   небольшую прозрачность;
-   спокойные цвета;
-   избегать ярких заливок.

------------------------------------------------------------------------

## Хиты

Хитом считается песня с рейтингом:

    rating >= 242

Хиты:

-   отображаются первыми;
-   отмечаются звездочкой ⭐;
-   при сортировке идут выше остальных.

------------------------------------------------------------------------

## Отправка списка

Порядок работы:

1.  Пользователь выбирает песни.
2.  Нажимает "Отправить список".
3.  Открывается окно выбора мессенджера.
4.  Список копируется.
5.  Пользователь вставляет его в чат.

Предварительный текст не содержит рекламы или упоминания видео.

------------------------------------------------------------------------

## Добавление новых тегов

Алгоритм:

1.  Добавить замену в конвертер:

``` json
"старый тег": "новый тег"
```

2.  Добавить новый тег в список tags:

``` json
"новый тег": {
  "group": "genre",
  "weight": 50
}
```

3.  При необходимости изменить цвет группы.

------------------------------------------------------------------------

## Проверка перед загрузкой

Перед заменой файлов на сервере проверить:

-   открывается ли `index.html`;
-   загружается ли `songs.js`;
-   работают ли фильтры;
-   открывается ли окно отправки;
-   корректно отображаются хиты.

------------------------------------------------------------------------

## Рекомендации

Не редактировать вручную большой список песен в `songs.js`.

Правильный порядок:

CSV → конвертер → songs.js → загрузка на сайт.

Так сохраняются: - замены тегов; - цвета; - веса; - сортировка.


## Кнопка «Выбрать все хиты»

Теперь кнопка выбирает только хиты из текущего отображаемого списка с учетом активного тега и фильтров. Если выбран тег — выбираются только песни этого тега с рейтингом >= 242.
