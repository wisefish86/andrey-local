# Разбор импортированных скриптов — статус

**15.10.2026:** перенесены в `Скрипты/` 51 действующий файл комплексами, включая все пять этапов обработки заказов. Старые файлы из перенесённых комплектов в этой папке больше не являются рабочими; исходные версии остаются в истории GitHub.

**Удалено 26 явно архивных файлов/резервных версий** (ZIP, копии исходников) после их сохранения в истории Git. Экспортные ZIP из Anytype **не удалены**: это данные импорта, а не версии скриптов.

**Осталось на разбор:** старые LNK с абсолютными путями, AHK для FlowLauncher и выступлений, `# Починить`, единичные BAT в корне коллекции и архивные экспорты Anytype. Эти файлы не следует бездумно назначать рабочими ярлыками.

**Проверка:** целостность сохранённых blob в GitHub подтверждается ссылками на те же объекты при переносе. Исполнение и реальные внешние зависимости на Windows ещё не проверены.

Постоянное расположение активных инструментов — `Скрипты/Работа/` и `Скрипты/Личные/`; каталог ярлыков Windows автоматически обновляется в `Ярлыки/`.
