# Разбор коллекции скриптов — состояние на 15.10.2026

Получено через фоновую синхронизацию: **123 файла** в 3 основных направлениях — **«Для пения и личные»**, **«Для работы»**, **«Мультимедиа»**.

## Первичная классификация
- **Пение и музыка:** подготовка к выступлению, фонотека, распределение минусов, теги Mutagen, встроенная лирика, подготовка репертуара для сайта, AHK-скрипты. Части сценариев требуются Python, ffmpeg, PowerShell, MusicBee, Syncthing и установленное ПО; зависимости нужно проверить.
- **Работа:** цепочка пяти последовательных этапов обработки заказов, сборщик PDF-превью, NConvert/WebP, очистка CSV. Нужна проверка путей, drag-and-drop, библиотек Python и порядка этапов, особенно этапа удаления.
- **Мультимедиа:** нормализация звука в видео.
- **Не относить к действующим инструментам:** резервные ZIP/версии PY/PYW, старые LNK, входные CSV, экспортированные ZIP для импорта из Anytype. `# Починить` — явно не готовые инструменты.

## Подтверждённые проверки
- Большинство рабочих BAT используют соседние `.ps1`/`.py`/`.pyw` через `%~dp0`; переносить исходник отдельно от BAT **нельзя**.
- `[скрипт] Мониторинг папок.bat` содержит старый абсолютный путь на `D:\YandexDisk\Ресурсы\Автоматизация\...`; не переносить в рабочие сценарии без исправления и тестирования.
- `start.bat` репертуара вызывает `python converter.py` без перехода к каталогу скрипта; запуск через ярлык с другим рабочим каталогом может сломаться.
- `apply_all.bat` обновляет теги песен, `cleanup_order.py` удаляет лишнее; такие сценарии не тестировать на живых файлах без резервной копии и проверки `--check` / `-WhatIf`.

## Что реально сделано
- В рабочую библиотеку безопасно перенесён **копированием** один самостоятельный инструмент: `Скрипты/Личные/Сеть/Показать IPv4.bat`. Он не зависит от соседних файлов; после очередного обновления каталога создаётся BAT-ярлык.
- Оригиналы всей присланной коллекции оставлены без изменений. Это **первичная инвентаризация, не завершённая миграция**.
