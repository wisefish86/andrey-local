# Разбор коллекции скриптов — завершён по исполняемым файлам

Рабочие комплекты находятся в `Скрипты/Работа/` и `Скрипты/Личные/`.

Дополнительно перенесены и сохранены как рабочие:
- `Скрипты/Личные/Автоматизация/Flow Launcher/` — AutoHotkey v2 и BAT-запускатель.
- `Скрипты/Личные/Музыка/Панель громкости/` — AutoHotkey v2 и BAT-запускатель.
- `Скрипты/Личные/Файлы/` — создание маркеров `[ЯД]` перетаскиванием.
- `Скрипты/Личные/Мультимедиа/` — FFmpeg-нормализация звука видео.
- Показ IPv4 был перенесён ранее в `Скрипты/Личные/Сеть/`.

**Остаток 17 исполняемых/ярлыков устранён:** 4 действующих файла перенесены, 8 устаревших `.lnk`, 4 помеченных `# Починить` и один дублирующий BAT удалены из текущего дерева Git. В Git-истории удалённые версии можно восстановить.

Экспортные ZIP Anytype, данные и служебные файлы остались во входящих: это не рабочие скрипты и их не следует автоматически удалять как архивные версии кода. Отдельный существующий импортёр Anytype в Notion — в `Скрипты/Личные/Импорт из Anytype в Notion/`.

**Проверка на Windows:** исходники AHK v2 прочитаны, BAT сохраняют соседство с исходниками; работа AHK, AutoHotkey-ассоциаций, FFmpeg, ярлыков и прочих программ непосредственно на компьютере не подтверждена.
