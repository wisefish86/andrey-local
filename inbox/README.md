# Входящие файлы для работы с ChatGPT

Это временная папка обмена через GitHub. Помещайте сюда изображения, CSS, JS, HTML и архивы, которые нужно разобрать или подключить к проектам.

**Как работать:**
1. На компьютере добавьте файлы в `inbox/` внутри локального репозитория `andrey-local`.
2. Синхронизируйте/отправьте изменения в GitHub штатным способом (`Синхронизация.bat`, если он обслуживает этот репозиторий).
3. В чате сообщите, что новые файлы лежат в `wisefish86/andrey-local/inbox/` и к какому проекту относятся. ChatGPT прочитает файлы из GitHub и внесёт согласованные изменения в соответствующий проектный репозиторий.
4. После обработки входящие файлы можно удалить отдельным коммитом; не удалять их автоматически.

**Важно:** репозиторий сейчас **публичный**. Не размещайте здесь пароли, ключи, приватные данные, личные документы или конфигурацию с секретами. Для конфиденциальных файлов используйте приватный репозиторий. Большие файлы и архивы могут упираться в ограничения GitHub; загружайте только необходимое.

Не подключайте файлы сайта непосредственно из этой папки; GitHub проекта содержит готовый код, а `inbox/` — временные исходники.
