# Inbox — обмен файлами с ChatGPT

Помещайте новые файлы в `inbox/` (кроме `done/`), затем синхронизируйте локальную копию с GitHub.

После обработки ChatGPT переносит обработанные входящие файлы в `inbox/done/` (с сохранением относительных путей). Это **статус обработки**, а не доказательство успешного FTP-деплоя. Статус публикации нужно проверять отдельно.

Постоянные канонические копии ресурсов находятся в `reference/magazinot/`, исходный код сайта — в репозитории `magazinot-dev-pages`. Папку `done/` можно очистить позднее отдельным согласованным действием, но не удалять из неё файлы автоматически.

**Внимание:** `andrey-local` публичный. Нельзя добавлять сюда пароли, ключи, конфиденциальные данные и персональные документы.
