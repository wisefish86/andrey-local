# Inbox — входящие материалы для разбора с ChatGPT

Это **одна входящая папка** для безопасных файлов, которые Андрей вручную размещает в локальном `andrey-local`. Фоновая Git-синхронизация передаёт их в GitHub. **Интеллектуальный разбор запускается по просьбе Андрея** («разбери inbox»), а не автоматически при появлении файла.

## Маршруты
- `magazinot/assets/` — новые ресурсы сайта: изображения, SVG, CSS, и прочие исходники для подготовки и распределения.
- `scripts/` — скрипты и связанные небольшие файлы, которые нужно изучить и включить в библиотеку `Скрипты/`.
- `review/` — неопределённые небольшие материалы для анализа и выбора назначения.
- `done/` — уже обработанные исходные входящие файлы; **не место постоянного хранения**. Существующее содержимое сохраняется.

## После разбора
1. Определить проект и назначение, сверить с существующими именами и версиями; не смешивать канонические исходники и временные файлы.
2. Постоянные ресурсы MagazinOT класть в `reference/magazinot/`, сайт/DEV-код менять в репозитории `magazinot-dev-pages`. Общие скрипты — в `Скрипты/` этого репозитория.
3. После проверки сохранения канонической копии исходник можно переводить в `inbox/done/` с сохранением понятного контекста. Не удалять содержимое `done/` автоматически.
4. Выгрузка в OSS/FTP — отдельная операция, наличие файла в `done/` **не означает публикацию**.

Не создавать новую отдельную систему Inbox под каждый проект: при необходимости дополнять подпапки по назначению. Входящие файлы в публичном репозитории доступны публично; помещать только то, что Андрей решил публиковать.
