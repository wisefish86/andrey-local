# Входящие скрипты

Сюда помещай новые BAT, PS1, PY, PYW, JS и связанные небольшие файлы для анализа и включения в общую библиотеку.

После проверки и при необходимости создания BAT-запускателя постоянный код размещается в тематическом подразделе `Скрипты/`. Ярлыки создаются существующим генератором для BAT/PYW. Ничего здесь не запускается автоматически.
