# ⌨️ Мои горячие клавиши и сокращения

Быстрая памятка для Windows. **Win** — клавиша с логотипом Windows; **Пробел** — Space.

## 🎙️ Handy — голосовой ввод

| Сочетание | Действие |
|---|---|
| **Ctrl + Пробел** | Начать / управлять диктовкой Handy (зависит от установленного режима) |

## 🔎 Flow Launcher — поиск и запуск

| Сочетание | Действие |
|---|---|
| **Alt + Пробел** | Открыть Flow Launcher |

## ✨ Espanso — текстовые сокращения

Это **не сочетания клавиш**, а текст, который нужно напечатать:

| Напечатать | Действие |
|---|---|
| **`ррр`** | Рабочие шаблоны / сокращения |
| **`ммм`** | Личные шаблоны / сокращения |

> Результат зависит от твоих текущих правил Espanso.

## 🪟 Windows — самое полезное

| Сочетание | Действие |
|---|---|
| **Win + L** | Заблокировать экран |
| **Win + E** | Открыть Проводник |
| **Win + D** | Показать / вернуть рабочий стол |
| **Win + Shift + S** | Сделать снимок части экрана |
| **Win + V** | Открыть историю буфера обмена (если включена) |
| **Win + I** | Открыть параметры Windows |
| **Win + ← / →** | Прикрепить окно к половине экрана |
| **Win + Tab** | Представление задач и виртуальных рабочих столов |
| **Alt + Tab** | Переключить активное окно |
| **Alt + F4** | Закрыть активное окно |
| **Ctrl + Shift + Esc** | Открыть Диспетчер задач |
| **Ctrl + C / V / X** | Копировать / вставить / вырезать |
| **Ctrl + Z / Y** | Отменить / повторить действие (в поддерживающих программах) |
| **Ctrl + A** | Выделить всё |

## 📌 Как открыть за два клика

1. Открыть этот файл `Горячие клавиши.md` через MarkText (или другой Markdown-просмотрщик).
2. В Проводнике нажать на файл правой кнопкой → **Показать дополнительные параметры** (если есть) → **Отправить → Рабочий стол (создать ярлык)**.
3. Ярлык на рабочем столе ведёт к файлу в `andrey-local`; после синхронизации GitHub памятка обновляется без создания новой копии.

**Как дополнять:** новые личные сочетания добавляй в соответствующий раздел; для новых приложений создавай отдельный раздел.
