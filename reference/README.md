# Reference — проверенные исходники

Здесь хранятся **постоянные эталонные материалы**, к которым ChatGPT обращается при доработках. Это не папка для новых входящих.

- Новое сначала помещай в `inbox/`.
- После проверки и определения назначения материал переносится сюда в тематическую папку.
- Не удаляй и не переименовывай эталоны без проверки зависимостей.
- Исходный код сайта хранится отдельно — в `magazinot-dev-pages`.
