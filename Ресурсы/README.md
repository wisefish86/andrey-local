# Ресурсы — общие файлы инструментов

Сюда складываем **общие ресурсы скриптов**, а не входящие файлы или результаты их работы.

- `Иконки/` — исходные SVG, готовые ICO и правила назначения значков ярлыкам.
- Новые SVG/ICO создаются через принятую систему Lucide + GitHub Actions.

Для файлов на разбор используй `inbox/`, а не этот раздел.
