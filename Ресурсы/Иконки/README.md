# Иконки для ярлыков Windows

Здесь храним изображения, используемые для ярлыков к скриптам: исходники `.svg` и готовые `.ico`. Не складывать сюда рабочие файлы и отчёты.

- Windows-ярлык (`.lnk`) для поля «Сменить значок» обычно требует `.ico` (либо значок из `.exe`/`.dll`). Один SVG сам по себе не назначается ярлыку.
- Для разных масштабов Windows готовый ICO желательно собирать с размерами 16, 24, 32, 48 и 256 px; прозрачный фон.
- Сами скрипты и BAT-запускатели остаются в `Скрипты/`. Отдельную локальную папку с ярлыками можно разбить по проектам: ярлыки указывают на существующие BAT и не дублируют код.
- **Внимание:** локальные ярлыки зависят от абсолютного пути компьютера, поэтому массово переносить их или менять структуру репозитория без проверки нельзя.
