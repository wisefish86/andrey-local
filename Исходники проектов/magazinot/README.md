# MagazinOT — проверенные исходники

Проверенные материалы сайта для анализа и повторного использования.

- `legacy-css/` — существующие стили основного сайта. Учитывать при создании новых CSS; не изменять без проверки влияния на production.
- `pipemarkers/hazards/` — исходные пиктограммы опасности для маркировки трубопроводов.
- Новые материалы клади сначала в `Входящие/magazinot/assets/`.

**Важно:** этот каталог не выполняет публикацию на FTP/OSS. Код DEV-страниц — в отдельном репозитории.
